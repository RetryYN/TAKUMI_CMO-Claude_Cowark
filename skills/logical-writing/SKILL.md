# ロジカルライティング

**対象領域: 意思決定を動かす文書**

データと論理で意思決定を支援する。戦略提案、市場分析レポート、KPI報告、経営層への報告資料。

> **書き手の立場**: 匠CMO は自社ブランドの意思決定を支える。読み手は「投資判断をする人」であり、
> **説得されたい人ではなく、判断材料が欲しい人**。都合の悪い数字を落とした資料は、
> 一度でも露見すればそれ以降の全報告の信頼を失う。

## なぜ論理構造が要るか

> **感情（ストーリー）で関心を作り、論理（データ）で決裁を通す。**

- 「なんとなく伸びています」→ 判断できない
- 「3つの観点で見て、この施策に寄せる根拠は…」→ 判断できる

## 基本原則

### 1. 主張は1つに絞る

1文書 = 1主張。「結局何を言いたいのか」に30秒で答えられること。

### 2. 主張 → 根拠 → 具体例の三層構造

```
主張:  「記事の新規本数を減らし、既存のリライトに寄せるべき」
 ├─ 根拠1: 「新規の平均掲載順位が3ヶ月連続で下がっている」
 │   └─ 具体例: Search Console の推移（期間・母数つき）
 ├─ 根拠2: 「リライトした12本は平均で順位が上がった」
 │   └─ 具体例: 施策前後の比較表（対象記事一覧つき）
 └─ 根拠3: 「制作工数はリライトの方が3割少ない」
     └─ 具体例: 工数実績
```

### 3. MECE（漏れなく、ダブりなく）

課題を分解するときは、分解の軸を先に宣言する。軸が言えない分解は、たいてい漏れている。

## テンプレート

### 戦略提案書

```markdown
## 1. エグゼクティブサマリー
[結論: 何を提案し、どんな効果が見込めるか — 3行以内]

## 2. 現状分析
| 指標 | 現状 | 前期 | 目標 |
|---|---|---|---|
※出所と集計期間を必ず併記。GA4 の数値は推定値であることも明記（→ ga4-jp）

### 課題の構造化
```
[結果指標]が伸びない
├─ [中間指標A]が足りない
│   ├─ [原因1]
│   └─ [原因2]
└─ [中間指標B]が足りない
    └─ [原因3]
```
※分解の軸を1行で宣言してから分解する

## 3. 提案内容
| 施策 | 効果 | 工数 | 優先度 |
|---|---|---|---|
※効果は KPIツリーのどのノードを動かすかで書く（→ kpi-design-jp）

## 4. 投資対効果
- 現状: [X]（前提: …）
- 提案後: [Y]（前提: …）
- **差分: [Z]**
※**広告費を前提にした試算は書かない**（ゼロ広告費）。工数・時間・機会損失で測る

## 5. リスクと対策
| リスク | 影響度 | 発生確率 | 対策 |
|---|---|---|---|
※「効果が出なかった場合にどう気づくか」を必ず1行入れる

## 6. スケジュール
| Phase | 期間 | 内容 |
|---|---|---|

## 7. 次のステップ
[具体的なアクション・担当・期限]
```

### KPIレポート（月次/週次）

```markdown
## [期間] KPIレポート

### サマリー
[結論を1〜2行で: 何が順調で、何が課題か]

### KPI推移
| 指標 | 目標 | 実績 | 達成率 | 前期比 |
|---|---|---|---|---|
※北極星・ドライバー・**ガードレール指標**を分けて並べる。
　ガードレールは達成率ではなく「閾値を割っていないか」で見る（→ kpi-design-jp）

### So What?（数字の解釈）
- [指標]が低下 → **原因**: [要因。特定できていなければ「要因未特定」と書く]
- [指標]が向上 → **要因**: [同上]

### 改善アクション
| アクション | 担当 | 期限 | 期待効果（どのノードを動かすか） |
|---|---|---|---|
```

## 論理の誤りチェックリスト

- [ ] **「良くなっています」に根拠はあるか**（何をもって良い？ 比較対象は？）
- [ ] **サンプルサイズは十分か**（1件の成功事例で全体を語っていないか）
- [ ] **相関と因果を混同していないか**（「変えた週に増えた」だけなら**要因未特定と明記**する）
- [ ] **暗黙の前提は正しいか**（「この施策が最適」は検証されているか）
- [ ] **比較は公平か**（自社に有利な軸・期間だけ選んでいないか）
- [ ] **都合の悪い数字を落としていないか**（落とすくらいなら載せて解釈を書く）
- [ ] **推定値を実測値のように書いていないか**（GA4 のセッション数・しきい値で消えた行 → ga4-jp）
