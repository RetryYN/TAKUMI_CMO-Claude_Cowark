# コピーライティング

**対象領域: 短い言葉で価値を可視化する**

形のないサービス・価値を、短い言葉で見えるようにする。読み手の心を掴み、次の行動を促す。

> **ゼロ広告費の前提**: 対象は**オーガニックな接点**の短文 — 記事タイトル・SNS投稿・LP見出し・
> メール件名・バナーの文字入れ。**有料広告のクリエイティブは扱わない**。
> 広告は枠を買って何度も出せるが、オーガニックは**一度で止められるかどうか**しかない。だから短さが効く。

## コピーの2大分類

### イメージコピー（ブランディング目的）

- **目的**: ブランドの世界観・価値観を伝える。直接売らない
- **効果**: 記憶に残る、好感度、**指名検索を増やす**（→ `skills/kpi-design-jp` のシェア・オブ・サーチ）
- **使いどころ**: タグライン、ブランドの約束、企業紹介

```
「はたらく、を変える。」（9文字）
「小さく試す。」（6文字）
「あとで読む、を減らす。」（11文字）
```

### セールスコピー（行動喚起）

- **目的**: 今すぐ読む・登録する・問い合わせる
- **効果**: クリック率、キーイベント率に直結
- **使いどころ**: 記事タイトル、LP見出し、メール件名、CTA

```
「30分で、下書きが1本。」（12文字）
「無料で試せます。」（8文字）
「まず読むだけでも。」（9文字）
```

## 文字数の鉄則

> **最強は7文字。最大でも13文字。**

| 文字数 | 評価 | 理由 |
|---|---|---|
| **7文字** | ★★★ 最強 | 一目で入る、記憶に残る |
| 8〜10文字 | ★★☆ 良い | 十分短い |
| 11〜13文字 | ★☆☆ 許容 | これが限界 |
| 14文字以上 | ☆☆☆ NG | 削り直す |

**文字数は目視で数えず機械で確認する**: 生成後に必ず `python3 -c "print(len('候補文'))"` 相当で
全候補を実測する（**句読点「、」「。」も1文字**。2026-07-24 実測: 目視カウントが句読点を数え漏れ、
全候補で1字少なく申告して13字基準の逸脱を見逃した）。

**例外**: 記事タイトルは検索結果の表示上限に合わせて **32文字以内**（→ `skills/seo-jp`）。
この場合も上限は機械で数える。

## 無形の価値を扱う最大の壁

> **「形がない = 想像できない = 価値がわからない」**

### 解決策: 抽象を具体に変換する

| 無形のまま（NG） | 具体化（OK） |
|---|---|
| 「業務を効率化」 | 「会議が15分になった。」 |
| 「成長できる環境」 | 「3ヶ月で一人でできる。」 |
| 「充実のサポート」 | 「返信は、その日のうちに。」 |
| 「使いやすい設計」 | 「説明書、ありません。」 |
| 「やりがいのある仕事」 | 「"ありがとう"が日常。」 |

## コピー作成フレームワーク

### 型1: 体言止め（最短・最強）
```
「次の一手。」（5文字）
「読まれる記事。」（7文字）
「本気の見直し。」（7文字）
```

### 型2: Before → After（変化を見せる）
無形の価値は「変化」が本体。
```
「迷いが、確信に変わった。」（11文字）
「日曜が怖くなくなった。」（11文字）
「探す時間が、ゼロに。」（10文字）
```

### 型3: 読み手の本音を代弁
```
「もう我慢しなくていい。」（11文字）
「このままでいいの？」（9文字）
「時間がない人へ。」（8文字）
```

### 型4: 数字 + ベネフィット
```
「準備30分、公開まで。」（11文字）
「工数、半分に。」（7文字）
「継続率92%。」（7文字）
```
**数字は実測値のみ。** 根拠のない数字は景表法の対象（→ `skills/ad-compliance-jp`）。

### 型5: 呼びかけ型（ターゲット直撃）
```
「一人で回す人へ。」（8文字）
「はじめての運用。」（8文字）
「続かなかった人へ。」（9文字）
```

### 型6: 断言・宣言型
```
「量より、再現性。」（8文字）
「広告は、使わない。」（9文字）
「妥協しない。」（6文字）
```

## 刺さるものを作る — 文字数は「外さない」ための条件にすぎない

**13字は制約であって、武器ではない。** 短く整えただけの言葉は、短くて印象に残らない言葉になる。
刺さるコピーは次のどれかを持っている。**1つも無いなら、字数を削る前に中身を探しに戻る。**

| 武器 | 効き方 | 例 |
|---|---|---|
| **具体の1点** | 抽象は流れる。数字・固有名・期間は止まる | 「会議が15分になった。」 |
| **読み手の内語** | 本人が心の中で言っている言葉をそのまま置く | 「このままでいいの？」 |
| **不都合の自認** | 自社に不利なことを先に言うと、後の主張が信用される | 「広告は、使いません。」 |
| **常識の逆** | 業界の当然を否定する。**根拠が要る** | 「量より、再現性。」 |
| **名前をつける** | 現象・手順・失敗に名前があると引用される | — |

**読み手の内語は自分で考えない。** `skills/voc-research-jp` で取った**顧客が実際に使った語彙**から拾う。
作り手が想像した「刺さりそうな言葉」は、たいてい作り手にしか刺さらない。

**「名前をつける」は特に効く。** 名前がつくと人は引用でき、引用されるとブランドと結びつく
（→ `skills/messaging-design-jp` の柱に紐づける）。

### 当たったコピーを捨てない

反応が良かった言い回しは記録し、**媒体を変えて再利用する**。反復こそが指名検索を作る
（→ `skills/winning-position-jp` の積み上げ）。**毎回新しく考え直すのは、蓄積を毎回ゼロに戻す行為。**

## ブラッシュアップ手法

1. **書き出す**（20案以上。質より量）
2. **13文字以下に削る**
   ```
   Before: 「あなたの運用に寄り添い最適な提案をします」（20文字）
   After:  「寄り添う運用。」（7文字）
   ```
3. **"形のない価値"を五感に変換する**
   ```
   Before: 「やりがいのある仕事」
   After:  「鳥肌が立つ瞬間。」（8文字）
   ```
4. **音読してリズムを確認**（七五調に寄せる。句読点でリズムを作る）
5. **機械で文字数を数える**（目視禁止）

## コピー評価チェックリスト

- [ ] **13文字以内か**（記事タイトルは32文字以内。**機械で数えたか**）
- [ ] **無形の価値が見える化されているか**
- [ ] **読み手が"自分ごと"と感じるか**
- [ ] **声に出して気持ちいいリズムか**
- [ ] **イメージ／セールス、目的に合っているか**
- [ ] **数字は実測値か**（No.1・最大級・保証表現があれば `skills/ad-compliance-jp` を通す）
- [ ] **煽っていないか**（偽の希少性・恐怖訴求は禁止 → `skills/psych-nudge-jp`）

## 媒体別最適化ガイド（すべてオーガニック）

| 媒体 | 文字数 | 構成ポイント | 効き方の鍵 |
|---|---|---|---|
| タグライン | 7文字 | ブランドの本質 | 全媒体で統一して使う（反復が指名検索を作る） |
| 記事タイトル | 〜32文字 | 検索意図 + 具体 | 検索結果一覧で選ばれること（→ seo-jp） |
| LP見出し | 7〜13文字 | 痛み or 憧れ | ファーストビューでの離脱を防ぐ |
| メール件名 | 〜13文字 | 用件が分かる | 開封されなければ本文は存在しない |
| X | 7〜10文字 + 絵文字 | 共感・本音代弁が強い | 引用・リポストで面が広がる |
| Instagram / Reels | 7文字 | ビジュアル主体・文字は補助 | プロフィールリンクへの動線 |
| バナーの文字入れ | 7文字 | 数字 + 変化、視認性優先 | 着地先とトーンを揃える（`templates/banner-compose.py`） |
| YouTube サムネ | 〜9文字 | 一目で内容が分かる | 縮小表示でも読めるサイズ（→ design-evidence-jp） |

**媒体をまたぐときは、骨子は同じままコピーを作り分ける。** 同一文面の一斉投稿はしない（→ `skills/sns-jp`）。
