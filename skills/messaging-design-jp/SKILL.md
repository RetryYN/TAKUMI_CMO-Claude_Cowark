# メッセージング設計

**面を張るには、張るべき主張が要る。** 匠CMO は「複数のモダリティ・複数の露出面から**反復して現れる**ものを
AI は認知し推奨する」を「AI に届く」の定義に置いている。**その反復する主張の正本がこのスキルの対象**。

> **ゼロ広告費との関係**: 広告なら同じコピーを出稿量で反復できる。オーガニックにその手段はない。
> **反復は、記事・投稿・動画・メールが全部同じことを言っていることによってしか作れない。**
> 媒体ごとに違うことを言えば、面はぼやけて点の集合に戻る。

## 0. 最初の関門 — 「結局、何を言っている会社なのか」

一文で答えられないなら、まだメッセージングは無い。**媒体を増やす前にここを決める。**

悪い状態の見分け方:

- 媒体ごとに違う訴求をしている（SNSでは手軽さ、LPでは高機能、記事では専門性）
- 主張が5つ以上ある（＝1つも覚えられていない）
- 主張が形容詞でできている（「高品質な」「使いやすい」— 誰でも言える＝何も言っていない）

## 1. メッセージングハウス

```
        ┌─────────────────────────────────┐
   屋根 │  ポジショニングステートメント（1文）  │  誰に・何を・なぜ我々から
        ├───────┬───────────┬───────────┤
   柱   │  柱1   │    柱2     │    柱3     │  言い続ける主張（最大3つ）
        ├───────┴───────────┴───────────┤
   土台 │       証拠（事実・数字・事例）        │  各柱を支える検証可能なもの
        └─────────────────────────────────┘
```

### 屋根 — ポジショニングステートメント

**1文。** 型: 「**〈誰〉の〈どんな状況〉に対して、〈何〉を提供する。〈なぜ我々からか〉。**」

- 競合が同じ文を書けるなら、それはポジショニングではない
- **顧客の言葉で書く**（自社の用語ではなく → `skills/voc-research-jp` で取った語彙）
- 検証されていないなら「仮」と明示する（`cmo-strategist` の作法と同じ）

### 柱 — 言い続ける主張は**最大3つ**

**増やすほど、1つも残らない。** 4つ目を足したくなったら、既存の1つを落とすか、その4つ目が
既存の柱の言い換えでないかを確かめる。

各柱は次を満たす:

| 条件 | 満たさない例 |
|---|---|
| **証拠がある**（事実・数字・事例） | 「使いやすい」← 何をもって？ |
| **競合が同じことを言えない** | 「品質にこだわっています」 |
| **顧客が気にしている**（VOC で確認済み） | 作り手だけが誇っている技術的特徴 |
| **1文で言える** | 説明に3段落要るものは柱ではない |

### 土台 — 証拠

**証拠のない柱は主張ではなく願望。** 証拠は検証可能な形で持つ:

- 数字（**母数と期間を併記**。無いなら書かない）
- 事例（**実在するもののみ。許諾を取る**）
- 仕組みの開示（どうやってそれを実現しているか）
- 第三者の評価（引用元を明示）

**証拠が用意できない柱は、柱から降ろす。** 言い続けられないものを柱に置くと、
どこかで誇張に転ぶ（→ `skills/ad-compliance-jp`）。

## 2. 言わないことを決める

**メッセージングの半分は「言わないこと」。** ここを決めないと、機会があるたびに主張が増える。

- **扱わない領域**（うちはこれはやらない）
- **使わない表現**（業界の常套句・誇張表現・比較のしかた）
- **競合の否定をしない**（比較広告は景表法の対象。相対的な優位は事実で示す）

`brand.yaml` のブランドガイド（トーン・NG）と接続する。

## 3. 媒体への展開 — 骨子は同じ、形だけ変える

**一貫性とは「同一文面」ではなく「同一骨子」。** 同じ文を貼り回すのは一貫性ではなく手抜きで、
媒体ごとの型を無視すれば読まれない（→ `skills/sns-jp`）。

| 媒体 | 変えるもの | 変えないもの |
|---|---|---|
| 記事 | 長さ・論証の細かさ | **どの柱の話か** |
| SNS投稿 | 語り口・長さ・形式 | **主張の骨子** |
| 動画 | フック・尺・見せ方 | **結論** |
| メール | 相手・タイミング | **証拠** |
| LP | 順序・視覚 | **ポジショニング** |

**1つの発信は、必ずどれか1つの柱に紐づく。** 紐づかない発信は「今回だけの思いつき」であり、
面を薄くする。**紐づけられないなら出さないか、柱を見直す。**

## 4. 一貫性の点検（ドリフトの検出）

発信は放っておくとズレる。**四半期に1度、直近の成果物を並べて点検する**（部品: `docs/parts/messaging-audit.md`）。

| 見るもの | 判定 |
|---|---|
| **どの柱にも紐づかない発信の比率** | 高いほどドリフトしている。**3割を超えたら柱かオペレーションのどちらかが壊れている** |
| **柱ごとの被覆** | 1つの柱に9割寄っていたら、他の柱は実質存在していない |
| **矛盾** | 別々の媒体で逆のことを言っていないか |
| **語彙のブレ** | 同じものを別の名前で呼んでいないか（検索でも別物として扱われる → `skills/seo-jp`） |

**点検の結果は2択**: 発信を柱に戻すか、**柱を現実に合わせて更新する**か。
「ズレているが放置」を選ばない。ただし**柱を頻繁に変えない** — 変えた瞬間、それまでの反復が無駄になる。

## 5. 見直しの周期

| 対象 | 周期 | 変える条件 |
|---|---|---|
| ポジショニング | 年1回 | 顧客・競合・提供価値のいずれかが実際に変わったとき |
| 柱 | 半年に1回 | 証拠が失われた／顧客が気にしなくなった（VOC で確認） |
| 表現・言い回し | 随時 | 伝わっていないと分かったとき |
| **点検（ドリフト）** | **四半期** | — |

**朝令暮改が最大の敵。** 反復が効くのは、同じことを言い続けた期間に比例する。

## 6. よくある失敗

- **柱が5つ以上ある**（覚えられないので、1つも伝わらない）
- **柱が形容詞でできている**（「高品質」「親切」— 誰でも言える）
- **証拠のない柱を置く**（どこかで誇張に転ぶ）
- **媒体ごとに違うことを言う**（面がぼやけて点の集合に戻る）
- **柱をコロコロ変える**（反復の蓄積が毎回ゼロに戻る）
- **顧客に確かめずに決める**（作り手が誇りたいことと、顧客が気にすることは一致しない → `skills/voc-research-jp`）

## 出典・確からしさ
