# ストーリーテリング

**対象領域: 形のない価値を「体験」として伝える**

抽象的な価値・変化・想いを物語で伝える。顧客の変化、創業の経緯、ブランドが何を大事にしているか。

## なぜ物語が要るか

> **サービスは形がない。だから"物語"で見せる。**

- 機能一覧では伝わらない「使った実感」を物語で伝える
- 「この人と同じ状況だ」という自分ごと化を促す
- 数字だけでは伝わらない「人の温度」を届ける

**ゼロ広告費との関係**: 物語は保存・引用・再訪を生む形式で、指名検索とシェア・オブ・サーチを押し上げる。
広告で反復露出を買えない以上、**一度読んだ人の記憶に残るかどうか**が効き方を決める（→ `skills/kpi-design-jp`）。

## 基本原則

### 1. 主人公は読者が共感できる人

- 輝かしい経歴の人より「自分と地続きの人」の方が刺さる
- 読者と同じ悩み・不安を持っていた人
- 「この人ができたなら、自分も」と思わせる

### 2. 葛藤がなければ物語ではない

- 「導入して便利です」→ 退屈（誰も読まない）
- 「やめようと思った。でも…」→ 引き込まれる
- **失敗・弱さ・迷いを見せることが信頼になる**

### 3. 抽象を五感で描写する

- 抽象的な価値を、具体的なシーンに変換する
- 「やりがい」を語らない。やりがいを**感じた瞬間**を描く

### 4. 事実を曲げない（最優先）

物語の技法は**構成と描写にだけ使う**。起きていないことを書いた瞬間、それは作り話であり、
バレたときに失うのはその記事だけではない。

- **創作した体験談・数値・人物は書かない**
- 取材で聞いていない心情を「盛る」のも創作。**言っていないことは書かない**
- 実在の人物・企業を扱うなら**掲載許諾を取る**（本文・写真・実名すべて）
- 体験談・口コミの体裁を取るならステマ規制と打消し表示の対象（→ `skills/ad-compliance-jp`）

## 素材が足りないときは書き始めない

年表や箇条書きしか無い状態から物語は作れない。**足りないのは文章力ではなく素材**。

| 必要な素材 | 無いとどうなるか |
|---|---|
| **葛藤**（うまくいかなかった時期・迷い） | 平坦な自慢話になる |
| **転機**（何がきっかけで変わったか） | 因果が繋がらず「気づいたら成功していた」になる |
| **一人称の言葉**（本人が実際に言った表現） | 書き手の想像＝創作になる |
| **具体的なディテール**（日時・場所・数） | どこかで読んだ話になる |

**足りなければ取材・追加ヒアリングを提案する。** 埋めて書き上げない。

## ストーリーテンプレート

### ヒーローズジャーニー型（変化を描く）

```markdown
【日常】     変化する前の、当たり前だった状態
【きっかけ】 何が引っかかったのか
【試練】     うまくいかなかった時期（具体的に。ここを削ると物語が死ぬ）
【転機】     何が・誰が・どの一言が変えたのか
【成長】     何ができるようになったか（数字があれば添える）
【新しい日常】今どうなっているか。読者への橋渡し
```

### STAR型（導入事例・課題解決を描く）

```markdown
【Situation】 導入前の状況（数字つき）
【Task】      何が壁だったか。なぜ動けなかったか
【Action】    何をしたか。決め手になった気づき
【Result】    結果（**実測値のみ**。期間と条件を併記）
```

### 創業・ミッション型

```markdown
【原体験】   創業者が実際に直面した出来事（一人称・具体的に）
【問い】     そこで生まれた疑問
【決断】     何を掲げて始めたか
【現在】     今どこまで来たか（検証できる事実）
【約束】     これから何をするか
```

## 感情を動かすテクニック

### 五感で描写する

```
❌ 「大変な時期だった」
⭕ 「深夜2時、カップ麺の湯気の向こうに、まだ13件の未処理メールが光っていた」
```

### 会話を入れる（臨場感の最強ツール）

```
❌ 「上司に励まされた」
⭕ 「『あれ、君がいなかったら絶対に間に合ってない』
    朝礼でそう言われた時、不覚にも泣きそうになった」
```

※**実際に言われた言葉だけ**を使う。取材メモに無い台詞は作らない。

### Before/After を対比する

```
Before: 毎週2時間の企画会議が、決まらないまま終わる
After:  15分で決まり、残りは「どう良くするか」の話になった
```

### 具体的なディテール

- 「あるカフェ」→「渋谷のドトール2階の窓際席」
- 「たくさん」→「127件」
- 「ある日」→「導入3ヶ月目の金曜、17時半」

## 公開前チェック

- [ ] 実在の人物・企業の掲載許諾を取った
- [ ] 数字は実測値で、期間と条件を併記した
- [ ] 葛藤・転機・一人称の言葉が揃っている（欠けたまま美文で埋めていない）
