# ビジネスライティング

**対象領域: 相手のいる実務文書**

社内外のコミュニケーション文書。取引先への連絡、取材・掲載の依頼、問い合わせ対応、社内共有。

## 基本原則

### 1. 結論ファースト（PREP法）

- **Point**: 結論を最初に
- **Reason**: 理由
- **Example**: 具体例で補強
- **Point**: 結論を再度

**件名で用件が分かること。** 「ご連絡」「お世話になっております」だけの件名は開かれない。

### 2. 簡潔性

- 1文60文字以内
- 冗長表現の排除（「〜させていただく」→「〜します」）
- 箇条書きの活用
- **相手が取るべき行動と期限を1箇所にまとめる**

### 3. 相手の負担を減らす

- 判断に必要な情報を本文内に置く（「添付をご覧ください」で済ませない）
- 選択肢を出す（日程は3案、可否は Yes/No で答えられる形に）
- **断りやすさを残す**（返信の心理的コストが下がると返信率が上がる）

## 文書タイプ別テンプレート

### 依頼メール（取材・掲載・寄稿・登壇）

```
件名: 【ご相談】〇〇についての取材のお願い（[媒体名]）

〇〇株式会社 △△様

はじめてご連絡いたします。[会社名]の[名前]と申します。
[媒体名]で[テーマ]についての記事を制作しており、△△様にお話を伺えないかとご連絡しました。

■ お願いしたいこと
- 内容: [具体的に。何を聞きたいか]
- 所要時間: [X]分（オンライン）
- 掲載先: [URL]
- 公開前に原稿をご確認いただきます

■ なぜ△△様にお願いしたいか
[相手固有の理由。テンプレではないことが伝わる1〜2行]

■ ご返信について
[X月X日]までに可否だけお聞かせいただければ幸いです。
ご都合が合わない場合は、遠慮なくお断りください。
```

### 日程調整

```
件名: 【日程のご相談】[用件]

[名前]様

お世話になっております。[会社名]の[名前]です。
[用件]について、日程のご相談です。

■ 候補日時（いずれも所要[X]分）
① X月X日（月）14:00〜
② X月X日（水）10:00〜
③ X月X日（金）16:00〜

■ 形式: オンライン（[ツール名]）
■ 参加者: [役職・名前]

上記でご都合の良い日時をお知らせください。
別日程のご希望があれば調整いたします。
```

### お断り・見送りの連絡

```
[名前]様

お世話になっております。[会社名]の[名前]です。
[件名]について、検討結果をお伝えいたします。

慎重に検討いたしましたが、今回は見送らせていただくことになりました。

■ 理由
[差し支えない範囲で具体的に。「社内事情により」だけで済ませない]

■ 今後について
[次に繋がる可能性があれば具体的に。無ければ書かない]

ご対応いただいたお時間に、あらためて御礼申し上げます。
```

### 督促・リマインド

```
件名: 【リマインド】[用件]（[期限]まで）

[名前]様

お世話になっております。[会社名]の[名前]です。
[X月X日]にご連絡した[用件]について、念のためご確認のご連絡です。

■ お願いしていること: [1行]
■ 期限: [X月X日]

すでにご対応いただいていましたら、行き違いご容赦ください。
ご不明点や、期限の調整が必要でしたらお知らせください。
```

**督促は「相手が忘れている」前提で書かない。** 行き違いの可能性を先に置くと角が立たない。

### 社内共有

```
■ 件名: [1行で結論]
■ 背景: [なぜこの共有をするか]
■ 事実: [起きたこと。数字と日付つき]
■ 所感: [主観であることを明示]
■ 依頼: [誰に何をいつまでに。無ければ「対応不要・共有のみ」と書く]
```

**事実と所感を混ぜない。** 混ざった共有は、後から読んだ人が判断を誤る。

## トーン＆マナー

| 相手 | トーン | 注意点 |
|---|---|---|
| 取引先・パートナー | ビジネスライク＋提案型 | 数字で語る、次の一歩を示す |
| 読者・ユーザー | 温かく＋対等に | 上から目線NG、専門用語を開く |
| 初回接触の相手 | 丁寧＋簡潔 | 相手固有の理由を1行入れる（テンプレ感を消す） |
| 社内 | 簡潔＋正確 | 事実ベース、主観は「所感」と明示 |

## NG表現

| NG | OK | 理由 |
|---|---|---|
| 「まだ決まりませんか？」 | 「ご検討状況はいかがですか？」 | 圧をかけない |
| 「ご存知の通り」 | （書かない） | 知らない相手を排除する |
| 「至急」だけ | 「[X日]までに」 | 主観的な緊急度は伝わらない |
| 「〜のほう」「〜になります」 | 「〜です」 | 曖昧表現 |
| 「取り急ぎ」で締める | 用件と次の一歩で締める | 雑な印象で終わる |

## 送信前チェック

- [ ] 件名だけで用件が分かる
- [ ] 相手の行動と期限が1箇所にまとまっている
- [ ] 事実と所感が分かれている
- [ ] 宛名・敬称・社名の誤りがない（**テンプレ変数の置換漏れは致命**）
- [ ] 一斉送信なら `pre-send-verifier` の監査と人間承認を経る（不可逆送出）

## 出典

**【社内基準】** — 本スキルの内容は**外部の一次情報ではなく、本プロダクトの型・運用経験**に基づく。
日本語ビジネス文書の一般的な慣習を実務用に整理したものであり、
**特定の規格・調査を根拠にしていない**。目安であって、引用可能な根拠ではない。
