# STP — 誰に売らないかを決める

**STP の実体は「絞り込み」である。** 全員に売ろうとすると誰にも刺さらない、
という話は誰でも知っているのに、実際の資料では**ターゲットが増えていく**。
理由は単純で、**外すのが怖いから**。

**このスキルの役割は、絞る判断に根拠を持たせること。** 勘で絞るから怖い。

> **ゼロ広告費との関係**: 広告費があれば、広いターゲットに薄く当てて反応を拾える。
> 使えない以上、**当たる場所を先に特定するしかない**。
> STP は「贅沢な整理」ではなく、**資源が無い側こそ必須**の工程。

## 0. 順番を守る（S → T → P）

| 段階 | 決めること | 失敗の形 |
|---|---|---|
| **S** セグメンテーション | 市場をどう切るか | **切り口が1つだけ**（年齢だけ、業種だけ） |
| **T** ターゲティング | どこを狙い、**どこを狙わないか** | 全部が「主要ターゲット」になる |
| **P** ポジショニング | その人の頭の中で**何の枠**に入るか | 「高品質で使いやすい」＝競合と同じ |

**Pから始めない。** 「こう見られたい」から始めると、
**そう見たい人が実在するかを確かめないまま**言葉だけ作ることになる。

## 1. S — 切り口を複数持つ（1軸だけで切らない）

**「30代女性」は、切り口ではなく人口統計上の集合**にすぎない。
同じ30代女性の中に、まったく違う購買行動がある。

| 切り口 | 例 | 使いどころ |
|---|---|---|
| **デモグラ**（年齢・性別・地域・世帯） | — | **単体では弱い**。他の軸と掛ける |
| **企業属性**（業種・規模・地域）BtoB | 従業員50〜300人 | 到達手段を決めやすい |
| **状況（いつ・どんな時）** | 引っ越し直後／担当になりたて | **最も打ち手に近い** |
| **用事（何を済ませたいか）** | 上司を説得したい | → `skills/customer-analytics-jp` の JTBD |
| **知識レベル** | 検討が初めて／比較段階 | 検索意図と直結（→ `skills/seo-jp`） |
| **行動** | 購入頻度・利用機能・流入経路 | **実データで切れる**（→ `customer-analytics-jp` の RFM） |
| **価値観・不安の核** | 失敗したくない／早く終わらせたい | → `skills/psych-target-jp` |

**「状況」と「用事」を必ず1つ入れる。**
属性だけで切ると「誰に届けるか」は決まっても「**何を言うか**」が決まらない。

### 切り口の作り方（推測で作らない）

1. **顧客の一次情報を読む**（→ `/匠顧客`）。**顧客自身の言葉で語られる違い**を拾う
2. **実データで切れる軸を優先する**（→ `/匠計測`。GA4・GSC・購買データ）
3. **切った結果、行動が違うことを確かめる**。**違いが出ない切り口は、切っていないのと同じ**

**AI が想像でペルソナを作らない。** 一次情報が無いなら、
**「推測である」と明記したうえで、確かめる手順を示す**（→ `/匠顧客`）。

## 2. T — 6つの基準で絞る（怖さではなく基準で決める）

各セグメントに次を当て、**狙う／狙わない**を決める。

| 基準 | 問い | 通らないと |
|---|---|---|
| **規模** | 十分な数がいるか | 頑張っても上限が低い |
| **到達可能性** | **どうやって届くか言えるか** | 良い相手でも届かない |
| **測定可能性** | その人が来たと分かるか | 効果が測れない |
| **反応の違い** | 他のセグメントと違う反応をするか | 分ける意味が無い |
| **競合の手薄さ** | 競合が向いていない相手か | 物量勝負になる |
| **自社適合** | 自社が本当に良い解を出せるか | 取っても続かない |

**ゼロ広告費では「到達可能性」が最も効く。** 広告で届けられない以上、
**検索・SNS・紹介・コミュニティのどれで届くかを1文で言えないセグメントは、狙えない**。

**「競合の手薄さ」の実例**: 同じ検索クエリの中に、上位が向いていない読み手がいることがある
（→ `skills/seo-jp`「同じクエリの中の、向かれていない読み手を取る」）。
**セグメントは市場全体ではなく、クエリ単位でも定義できる。**

### 絞った結果を1枚に書く

```markdown
## ターゲット（<ブランド名>）

**主ターゲット**: 〈状況＋用事で書く。属性だけで書かない〉
**なぜここか**: 〈6基準のうち、決め手になったもの〉
**どうやって届くか**: 〈1文。言えないなら選び直す〉
**狙わないと決めたもの**: 〈2つ以上。**理由つき**〉
**外れたと分かる条件**: 〈この読みが違ったと分かる観測〉
```

**「狙わないと決めたもの」が空欄なら、絞れていない。**
記録する理由は、**毎回同じ議論をやり直さないため**（→ `skills/winning-position-jp` §5）。

## 3. P — 頭の中の場所を取る

**ポジショニングは「自社をどう説明するか」ではなく「顧客の頭の中で、何の隣に置かれるか」。**

### ポジショニングマップの作り方（ここを間違える人が多い）

1. **軸を、顧客が実際に比較に使っている基準から取る**
   （→ `/匠顧客`。「何と比べましたか」「決め手は何でしたか」）
2. **自社が有利な軸を選ばない。** 選んだ時点でマップは自己申告になる
3. **軸が相関していないか確かめる**（「価格が高い⇔品質が高い」は同じことを2回言っている＝
   斜め一直線に並ぶだけでマップにならない）
4. **競合を実際に置く**（実物を見て置く → `skills/growth-teardown-jp`）
5. **空白が「誰もいない場所」なのか「誰も欲しがらない場所」なのか**を確かめる

**空白＝チャンスとは限らない。** 空いている理由が「需要が無いから」であることは非常に多い。
**空白を見つけたら、そこに人がいるかを `/匠顧客` で確かめる**（ここを飛ばすと最も高くつく）。

### ポジショニングの1文

```
〈ターゲット（状況＋用事）〉にとって、
〈自社〉は〈カテゴリの括り〉の中で、
〈提供価値〉を提供する唯一の存在である。
なぜなら〈根拠＝非対称な強み〉だからだ。
```

- **「唯一」が言えないなら、括りを変える**（→ `skills/winning-position-jp` §3 カテゴリの再定義）
- **根拠が「品質」「丁寧さ」なら、それは根拠ではない**（競合も同じことを言う）
- **この1文が `messaging.md` の上流**になる（→ `skills/messaging-design-jp`）

## 4. STP を検証する（決めた後が本番）

**STP は仮説である**（→ `skills/hypothesis-design-jp`）。

| 検証すること | 方法 |
|---|---|
| そのセグメントが実在するか | `/匠顧客`・GSC の検索クエリ・問い合わせの内訳 |
| 反応が本当に違うか | セグメント別の転換率・読了率（→ `/匠計測`） |
| ポジショニングが伝わっているか | 顧客が**自分の言葉でどう説明するか**を聞く |
| 届いているか | 流入の構成（→ `skills/kpi-design-jp`） |

**「顧客が自社をどう説明するか」が、実際のポジショニング。**
こちらが書いた1文ではない。ズレていたら、直すのは顧客ではなく発信の側。

## 5. 見直しの周期

| 対象 | 周期 | 見直す条件 |
|---|---|---|
| セグメントの切り口 | 年1回 | 顧客の語彙が変わった／新しい行動データが取れた |
| ターゲット | 半年 | 反応の差が消えた／到達手段が使えなくなった |
| ポジショニング | 年1回 | 競合が同じ括りに入ってきた |

**朝令暮改しない。** ポジショニングは**反復で頭に残る**もので、変えるたびに蓄積がゼロに戻る
（→ `skills/messaging-design-jp`）。

## 6. よくある失敗

- **Pから始める**（そう見たい人が実在するか確かめないまま言葉を作る）
- **切り口が属性1軸**（「30代女性」は集合であって切り口ではない）
- **状況・用事の軸が無い**（誰に届けるかは決まっても、何を言うかが決まらない）
- **一次情報なしでペルソナを作る**（推測なら推測と書く）
- **ターゲットが増えていく**（「狙わないもの」が空欄なら絞れていない）
- **到達手段を言えないセグメントを選ぶ**（ゼロ広告費では致命的）
- **自社が有利な軸でマップを作る**（自己申告のマップに意味は無い）
- **相関する2軸でマップを作る**（斜めに一直線に並ぶだけ）
- **空白をチャンスと決めつける**（誰も欲しがらないから空いている場合が多い）
- **ポジショニングを自己申告で完結させる**（顧客の説明の仕方が実際のポジション）
- **半年ごとに作り直す**（反復で効くものを、反復の前に変えている）
