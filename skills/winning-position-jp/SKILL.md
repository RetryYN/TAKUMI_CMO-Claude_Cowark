# 勝ち筋の設計

**広告を使える相手と同じ土俵で戦えば、必ず負ける。** 資本の殴り合いに収束するからだ。
ゼロ広告費で勝つ唯一の方法は、**土俵を選ぶこと**。

このスキルは「どう戦うか」ではなく「**どこで戦うか**」を決める。順番を間違えると、
どれだけ良いコンテンツを作っても、良いコンテンツを大量に出せる相手に埋もれる。

## 0. 最初の問い — 「なぜ我々が勝てるのか」

一文で答えられないなら、まだ戦略はない。次のどれかが言えなければ勝ち筋は無い:

1. **その場所では、広告費が効きにくい**（金で買えない何かが要る）
2. **時間が経つほどこちらが有利になる**（積み上げが効く）
3. **我々にはあって、競合には無いものがある**（非対称）

「良いものを作れば選ばれる」は勝ち筋ではない。**競合も良いものを作っている。**

## 1. 広告費が効きにくい場所を選ぶ

ゼロ広告費が**不利にならない**のは、次の性質を持つ領域。**ここを探す。**

| 性質 | なぜ広告が効きにくいか | 具体 |
|---|---|---|
| **検討期間が長い** | 一度の露出では決まらない。何度も戻ってくる先が要る | 高単価・導入に社内調整が要る・失敗コストが高い |
| **信頼が必要** | 広告で「信頼できます」と言っても信頼されない | 専門性・実績・人柄が判断材料になる領域 |
| **検索意図が深い** | 悩みが具体的で長い。広い露出では当たらない | 「◯◯ 失敗 原因」「◯◯ 向いてない人」 |
| **説明が要る** | 15秒で伝わらないものは広告と相性が悪い | 新しい概念・比較が必要・前提知識が要る |
| **母数が小さく単価が高い** | 広告は母数がないと回らない | ニッチ・専門職・特殊業種 |
| **人が集まる場がある** | コミュニティは金で買えない | 業界の集まり・特定の関心 |

**逆に、避けるべき場所**: 衝動買い・低単価・大量露出で決まる・比較検討が一瞬で終わる領域。
**そこは広告費の勝負で、参加した時点で負けている。**

## 2. 非対称な強みを見つける

**「強み」と「非対称な強み」は違う。** 非対称とは「**競合が同じことをやるにはコストがかかるが、
我々にはもう存在している**」もの。

### 探す場所

| 種類 | 問い | 見落としがちな例 |
|---|---|---|
| **実務の蓄積** | 我々が毎日やっていて、外から見えないことは何か | 失敗の記録・現場の判断基準・よくある落とし穴 |
| **独自のデータ** | 我々しか持っていない数字は何か | 自社の実測・顧客の傾向・処理件数 |
| **人** | 「この人だから聞きたい」と言われる人はいるか | 創業者・現場の職人・特定分野の第一人者 |
| **立場** | 我々だから言えることは何か | 業界の常識への異議・利害が絡まない立場 |
| **制約** | 我々の弱点は、裏返すと何になるか | 小さい＝速い／専門特化＝深い／広告を使わない＝媚びない |

**最後の「制約の裏返し」を飛ばさない。** ゼロ広告費そのものが立場になる
（「広告を出さないので、書けることがある」は競合には言えない）。

### 非対称かどうかの判定

- **競合が明日から真似できるか？** できるなら非対称ではない
- **真似するのに、彼らが何かを失うか？**（既存事業との矛盾・言えない立場）→ 失うなら**強い非対称**
- **我々にとってコストがゼロに近いか？**（既に存在するもの）→ 近いほど持続する

## 3. カテゴリを再定義する

**同じ土俵で2番手になるより、1番になれる土俵を定義する。**

比較されている土俵が不利なら、**比較の軸そのものを変える**。

```
今: 「〈既存カテゴリ〉の中の1社」
   → 比較軸は既存カテゴリの基準（規模・価格・機能数）で、こちらが不利

後: 「〈新しい括り〉の中で唯一の存在」
   → 比較軸を自分たちが強い側に置き直す
```

**再定義が成立する条件**（3つとも必要）:

1. **顧客がその括りを理解できる**（説明に3段落要る括りは成立しない）
2. **その括りで我々が実際に1番である**（言葉だけなら見抜かれる）
3. **その括りを求めている人が実在する**（→ `skills/voc-research-jp` で確かめる）

**やってはいけない**: 競合を貶めて自分の土俵を作ること（比較広告は景表法の対象 → `skills/ad-compliance-jp`）。
**新しい括りは、競合の否定ではなく顧客の状況から作る。**

## 4. 積み上げが効く形を選ぶ

ゼロ広告費の最大の武器は**複利**。広告は止めれば消えるが、積み上がる資産は消えない。

| 資産 | 積み上がり方 | 効かせ方 |
|---|---|---|
| **検索での存在** | 記事は消えず、被リンクと評価が乗っていく | 一過性の話題より、**長く読まれる問い**に答える |
| **指名検索** | 反復露出が名前を記憶に残す | 主張を変えない（→ `skills/messaging-design-jp`）。**シェア・オブ・サーチ**で測る |
| **顧客の口** | 満足した顧客が次を連れてくる | `/リテンション`・`/広報` |
| **蓄積した一次情報** | 出すほど「ここにしかない」が強まる | 自社データ・実測・失敗の公開 |
| **場**（コミュニティ・読者） | 人が人を呼ぶ | 続けること自体が参入障壁 |

**「今月の数字」のためだけの施策を、計画の過半にしない。** 積み上がらない施策は、
やめた瞬間ゼロに戻る。**そこで競合の広告費と正面衝突する。**

> **範囲の広さは `skills/scale-strategy-jp` が決める。** このスキルが「**どんな性質の土俵か**」
> （広告費が効きにくいか・積み上がるか・非対称か）を選ぶのに対し、scale-strategy-jp は
> 「**どこまで狭めるか**」を決める（射程距離・1位を取れるまでの細分化）。両方を通すこと。

## 5. 捨てる — 戦略の半分は「やらないこと」

**全部やる」は戦略ではない。** 資源が有限（→ `docs/parts/capacity-plan.md`）である以上、
集中しないと、どこでも1番になれない。

捨てる判断の順:

1. **勝てない土俵**（広告費で決まる領域）— 参加しない
2. **非対称な強みが効かない施策** — 他社がやったほうが上手いなら、やらない
3. **積み上がらない施策**（過半を占めていたら削る）
4. **どの柱にも紐づかない発信**（→ `skills/messaging-design-jp`）

**捨てたものは記録する。** 「検討した結果やらないと決めた」と「思いつかなかった」は別物で、
記録がないと毎回議論をやり直すことになる。

## 6. 勝ち筋を1枚に書く

```markdown
## 勝ち筋（<ブランド名>）

**戦う場所**: 〈どの領域か。なぜそこは広告費が効きにくいのか〉
**勝てる理由**: 〈非対称な強み。競合が真似するには何を失うか〉
**カテゴリの括り**: 〈我々は何の中の唯一か。顧客がその括りを理解できるか〉
**積み上げる資産**: 〈時間が経つほど有利になるもの〉
**やらないこと**: 〈参加しない土俵・やらない施策と、その理由〉
**外れたと分かる条件**: 〈この読みが間違いだったと分かる観測は何か〉
```

最後の1行を必ず書く（→ `skills/hypothesis-design-jp`）。
**勝ち筋も仮説である。** 反証条件のない勝ち筋は、ただの願望。

保存先: `knowledge/brands/<slug>/strategy/winning-position.md`。
**この1枚が、KPIツリー（`kpi-design-jp`）とメッセージング（`messaging-design-jp`）の上流**になる。

## 7. 見直しの周期

| 対象 | 周期 | 見直す条件 |
|---|---|---|
| 戦う場所 | 年1回 | 領域の性質が変わった（広告が効くようになった／競合が参入した） |
| 非対称な強み | 半年 | 競合が真似した／こちらが失った |
| カテゴリの括り | 年1回 | 顧客が別の括りで探すようになった |
| やらないこと | 四半期 | — |

**朝令暮改しない。** 積み上げが武器である以上、場所を変えるたびに蓄積がゼロに戻る。
**変えるのは「外れたと分かる条件」が観測されたときだけ。**

## 8. よくある失敗

- **「良いものを作れば選ばれる」で終わる**（競合も良いものを作っている）
- **強みを列挙して満足する**（非対称でなければ強みではない）
- **全方位に施策を張る**（どこでも2番手になり、どこでも勝てない）
- **積み上がらない施策で計画が埋まる**（やめた瞬間ゼロに戻る場所で戦っている）
- **カテゴリの再定義を言葉だけでやる**（顧客が理解できない括り・実際には1番でない括り）
- **競合の否定で土俵を作る**（景表法リスク。かつ、貶められた側のファンを敵に回す）
- **捨てる決断をしない**（「一応やっておく」が資源を溶かす）
- **反証条件を書かない**（間違った場所で戦い続けても気づけない）
