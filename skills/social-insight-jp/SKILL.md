# 社会文脈から人物像を組み立てる

**「30代・共働き・都市部」は、人物像ではない。条件の列挙である。**

人物像とは、**複数の条件が重なった結果、その人の一日がどうなっていて、
何に時間と注意を奪われ、何を諦めていて、何が起きたら動くのか**である。

このスキルは、**社会統計 → 生活条件 → 行動 → 心理**の順に降りる鎖を扱う。
どこか1段を飛ばすと、**属性から人格を決めつける**ことになる。

> **このスキルの最大の危険**: 統計を根拠にした断定は、**もっともらしく聞こえる**。
> 「単独世帯が34%だから、孤独を感じている」——これは推論ですらなく、飛躍である。
> **§6 の禁止事項を先に読むこと。**

## 0. 鎖の全体像（順番を守る）

| 段 | 何をするか | 使うもの | 飛ばすとどうなるか |
|---|---|---|---|
| **① 構造** | 日本社会で何が起きているかを統計で押さえる | §1・§2 | 世代論・印象論に流れる |
| **② 条件の交点** | **複数条件の重なり**で対象を定義する | §3 | 単一属性のステレオタイプになる |
| **③ 制約** | その交点にいる人の**時間・注意・金・関係**の制約 | §4 | 届かない設計を作る |
| **④ 情報接触** | どこで・いつ・どんな状態で情報に触れるか | §2 の媒体データ | 出しても見られない |
| **⑤ 行動の推論** | 制約から**やること・やらないこと**を導く | §5 | 願望を行動と混同する |
| **⑥ 心理の言語化** | 状況の言葉で書く（人格ではなく） | §5 | 決めつけの文章になる |
| **⑦ 反証** | 一次情報で確かめる | §7 | 推論が事実として独り歩きする |

**⑦を必ず回す。** ①〜⑥はすべて**推論**であり、
`/顧客の声` で確かめるまでは**仮説**である（→ `skills/hypothesis-design-jp`）。

## 1. 日本社会の構造を押さえる — どの統計が何に答えるか

**数字は古びる。だが「どの調査を見ればよいか」は古びない。** まずこの対応表を持つ。

| 知りたいこと | 見る統計（一次情報） |
|---|---|
| 人口・世帯数・年齢構成・地域 | **国勢調査 / 人口推計**（総務省統計局） |
| 世帯構造・所得・**生活意識** | **国民生活基礎調査**（厚生労働省） |
| **1日の時間の使い方**（家事・育児・仕事・余暇） | **社会生活基本調査**（総務省統計局） |
| 就業形態・非正規比率・共働き | **労働力調査**（総務省統計局） |
| 何にいくら使っているか（品目別・月別） | **家計調査**（総務省統計局） |
| **メディア接触時間・SNS利用率** | **情報通信メディアの利用時間と情報行動に関する調査 / 情報通信白書**（総務省） |
| 結婚・出産・子育ての意識 | **出生動向基本調査**（国立社会保障・人口問題研究所） |
| 消費者の見通し | **消費動向調査**（内閣府） |

**入口は e-Stat**（`https://www.e-stat.go.jp/`）。
**定義を必ず確認する** — 「世帯」「就業者」「単独世帯」の定義は調査ごとに違う。

## 2. 押さえておく構造的な事実（2026-07-25 時点で取得。**使う前に再確認**）

> **出所の扱いについて（重要）**: 以下は**調査名と出所を特定した公的統計**だが、
> **公式ページの本文をこちらで直接読めていない**（文字化けのため取得失敗）。
> **数値を対外的な資料に載せる前に、必ず原典を開いて確認すること。**
> 詳細は末尾の出典欄に記載した。

### 世帯（国民生活基礎調査 2023年）

- **単独世帯が最多で約34.0%**。次いで「夫婦と未婚の子のみ」約24.8%、「夫婦のみ」約24.6%
- **高齢者世帯のうち、単独世帯が約51.6%**、夫婦のみが約44.1%
- **生活意識が「苦しい」**: 児童のいる世帯 **62.1%**、高齢者世帯 **53.4%**

**読み方**: 「標準世帯（夫婦と子2人）」は**もはや多数派ではない**。
そして**児童のいる世帯の6割超が生活を「苦しい」と答えている** —
子育て層向けの訴求で「ちょっと贅沢を」が滑るのは、ここに理由がある可能性がある。

### 時間（社会生活基本調査 令和3年）

- **家事関連時間**: 男性 約**51分** / 女性 約**3時間24分**（差 約2時間33分。2001年の3時間3分から縮小）
- **6歳未満の子供がいる共働き世帯**: 夫の家事・育児 約**1時間54分** / 妻 約**7時間28分**

**読み方**: これは**可処分時間の話**である。
妻側に1日7時間半の家事育児がある家庭に、「じっくり読む長文」「平日夜のセミナー」を
届ける設計は、**内容の良し悪し以前に成立していない**。
**時間の制約は、訴求で覆せない。**

### 情報接触（情報通信白書 令和7年版／令和6年度調査）

- 平日: **インターネット 183.9分 > テレビ（リアルタイム）156.1分**
- 休日: インターネット 192.9分 / テレビ 189.2分
- **休日の40代で、インターネットの平均利用時間が初めてテレビを上回った**
- 行為者率では**10代〜50代でインターネットがテレビを超過**（平日・休日とも）
- SNS等の利用率（全年代）: **LINE 92.9%** / YouTube 81.5% / Instagram 54.8% /
  X 44.7% / TikTok 36.7% / Facebook 27.0%

**読み方**: **LINE がほぼ全年代の共通基盤**である一方、他の媒体は割れている。
「SNSをやる」ではなく「**どの面に、その人が、どの時間帯にいるか**」で選ぶ
（→ `skills/sns-jp`・`procedures/takumi-sns-line.md`）。

**注意**: 平均利用時間は**全年代の平均**であり、目の前の対象に当てはまるとは限らない。
**年代別・平日休日別で必ず分解する。**

## 3. 条件の交点で定義する（このスキルの中心）

**単一属性で切らない。** 属性1つは、行動をほとんど説明しない。

### 掛け合わせる6つの軸

| 軸 | 例 | 何が決まるか |
|---|---|---|
| **世帯・同居者** | 単身／夫婦のみ／未就学児あり／親の介護あり | **自由になる時間と、決定権** |
| **就業形態** | 正規／非正規／自営／管理職／交代勤務 | **時間帯の自由度・金の余裕・情報の入手経路** |
| **ライフステージの節目** | 入学・転職・引越し・介護開始・退職 | **需要が立ち上がる瞬間**（→ `skills/demand-timing-jp`） |
| **居住** | 都市/地方・持家/賃貸・通勤時間 | 移動時間＝**可処分時間と接触機会** |
| **金銭の余裕感** | 「苦しい」と感じているか | **価格の受け取られ方**（→ `skills/offer-design-jp`） |
| **情報環境** | 主に使う面・使う時間帯・端末 | **届く手段があるか**（→ `skills/stp-jp` の到達可能性） |

### 交点の書き方

```
〈世帯〉× 〈就業〉× 〈節目〉× 〈居住〉
→ 1日のうち自由になる時間: 〈いつ・何分〉
→ その時間に触れている面: 〈どこ〉
→ 使える金の感覚: 〈余裕あり／切り詰めている〉
→ 決定権: 〈自分だけ／配偶者と／上司の承認が要る〉
```

**「決定権」を必ず入れる。** BtoC でも**家庭内の合意**が要る買い物は多く、
BtoB では**使う人と決める人が違う**（→ `skills/sales-writing`）。
決定権を見落とすと、**説得する相手を間違える**。

### 交点は2〜3個に絞る

**掛け合わせを増やすほど、該当者は減る。**
6軸すべてを固定すると、実在するのは数人になる。
**「意思決定が変わる軸」だけを固定し、残りは幅を持たせる**（→ `skills/stp-jp` §2）。

## 4. 制約を書き出す（願望より先に、制約を見る）

**人は、したいことをするのではなく、できることをする。**

| 制約 | 問い | 施策への影響 |
|---|---|---|
| **時間** | まとまった時間はいつ、何分あるか | 尺・分量・配信時間 |
| **注意** | その時間、他に何をしているか（ながらか） | 音声/動画/テキストの選択 |
| **金** | 迷わず出せる額はいくらか | 価格帯・入口商品（→ `offer-design-jp`） |
| **関係** | 誰の合意が要るか | 説得材料・共有しやすさ |
| **知識** | 前提知識をどこまで持っているか | 説明の深さ（→ `seo-jp` の検索意図） |
| **手続き** | 面倒だと感じる工程はどこか | 摩擦の削減（→ `offer-design-jp` §2） |

**時間の制約は、訴求では覆せない。** 7時間半の家事育児がある人に
「30分の動画を見てください」は、内容がどれだけ良くても届かない。
**制約に合わせて形式を変える**のが正しい対応（→ `skills/breakout-content-jp`）。

## 5. 行動を推論し、心理を言語化する

### 推論の書き方（3点セットで書く）

```
条件: 〈交点。§3〉
制約: 〈§4 のどれが効くか〉
だから起きること: 〈行動。**観測できる形で**〉
根拠: 〈統計か／一次情報か／推測か。**必ず種別を書く**〉
```

**「だから起きること」は観測できる形で書く。**
「情報感度が高い」ではなく「**平日は通勤中の10分しか見ておらず、後で読む用に保存する**」。

### 心理の言語化 — 状況の言葉で書く

**やってはいけない書き方**（人格の断定）:

> 「効率を重視し、コスパにシビアで、承認欲求が強い」

**正しい書き方**（状況と、そのときの感じ方）:

> 「**夜9時、子どもを寝かせた後の30分が唯一まとまった時間**。
> その時間に調べ物をするので、**結論が先に書いていない記事は途中で閉じる**。
> 失敗すると次に試す時間が無いので、**「うまくいかなかった例」が書いてあるほうを選ぶ**」

**違いは3つ**:

1. **人格ではなく状況**を書いている（「シビア」ではなく「時間が無い」）
2. **観測できる行動**が入っている（閉じる／選ぶ）
3. **なぜそうするかの理由**が制約から出ている

**形容詞で人を語らない。** 「意識が高い」「保守的」「情報弱者」は、
**書き手の評価**であって対象の描写ではない。使った時点で分析が止まる。

### 心理の3軸に接続する

書いた人物像を、文面に落とすときは `skills/psych-target-jp` の3軸
（**不安の核／意思決定スタイル／関係段階**）へ渡す。
**このスキルは「なぜその不安があるのか」を構造から説明する側**で、
psych-target-jp は「**その不安をどう文面で扱うか**」を担う。

**心理学は不安の解消に使い、増幅（恐怖訴求・偽の希少性）に使わない**
（session-rules (3)・`skills/psych-nudge-jp`）。
**社会統計で不安を裏づけて煽るのは、最も悪質な使い方。**

## 6. 禁止（例外なし）

- **統計から個人を断定する**（**生態学的誤謬**）。
  「単独世帯が34%」は、**目の前の人が単身である確率でも、孤独である証拠でもない**
- **属性から人格・能力・価値観を決めつける**（年代・性別・地域・世帯・雇用形態・所得）
- **保護される属性で不利益な推論をする**（国籍・出自・障害・信条・健康状態・性的指向）。
  **これらを軸に「売れる/売れない」を推論しない**
- **読み手を「診断」する物言いをする**（プロファイルは**書き手側の内部判断に留める**。
  成果物に「あなたは◯◯タイプ」と書かない — session-rules (3)）
- **社会不安を煽る材料に使う**（「このままでは老後が」「周りはもう始めている」）
- **世代論をそのまま使う**（「Z世代は◯◯」は分布の話ですらないことが多い。
  **条件の交点で説明できないなら使わない**）
- **出典の無い数字を人物像の根拠にする**（→ `skills/quant-research-jp` §6）
- **個人が特定できる情報を人物像に混ぜる**（→ `privacy-auditor`）

## 7. 反証する — 推論を事実にしない

**①〜⑥はすべて推論である。** 次のどれかで確かめるまで、仮説として扱う。

| 確かめ方 | 何が分かるか |
|---|---|
| **`/顧客の声`**（過去と行動を聞く） | 制約と決定権が本当にそうか。**顧客自身の語彙** |
| **GSC の検索クエリ** | 実際に何を、どんな言葉で調べているか |
| **GA4 の曜日・時間帯・デバイス** | **いつ・どの端末で**見ているか（時間の制約の裏取り） |
| **問い合わせ・コメントの実物** | つまずいている工程（→ `/エンゲージメント`） |
| **小さく出して反応を見る** | 最も速い（→ `skills/hypothesis-design-jp`） |

**特に「時間帯・デバイス」は安く確実に裏が取れる。**
推論した「夜9時の30分」が実データと合わないなら、**人物像のほうを直す。**

**外れたら、条件・制約・行動のどこが違ったかを切り分ける**
（→ `skills/hypothesis-design-jp` §5 の3分類）。

## 8. 成果物の型

```markdown
## 人物像（<ブランド名> / <対象名>）
観測日: YYYY-MM-DD

### 条件の交点
〈世帯 × 就業 × 節目 × 居住〉／決定権: 〈誰の合意が要るか〉

### 制約

### 情報接触
面: 〈どこ〉／時間帯: 〈いつ〉／端末: 〈何で〉

### 起きること（観測できる形で）
- 〈行動〉— 根拠: 〈統計 / 一次情報 / 推測〉

### 状況の言葉（心理）
〈「〜のとき、〜なので、〜する」の形で3〜5文。形容詞で人を語らない〉

- 〈推測で埋めた箇所〉→ 確かめ方: 〈/顧客の声・GA4 等〉

〈この読みが違ったと分かる観測〉
```

保存先: `knowledge/brands/<slug>/knowledge/analysis/<date>-人物像-<対象>.md`。
**観測日を必ず書く**（統計は更新される）。

## 9. よくある失敗

- **属性の列挙を人物像と呼ぶ**（「30代・共働き・都市部」は条件であって像ではない）
- **統計から個人を断定する**（生態学的誤謬。集団の分布は個人を説明しない）
- **形容詞で人を語る**（「意識が高い」は書き手の評価。分析がそこで止まる）
- **世代論を根拠にする**（条件の交点で説明できないなら使わない）
- **制約より先に願望を書く**（人はできることをする）
- **時間の制約を訴求で覆そうとする**（形式を変えるのが正解）
- **決定権を見落とす**（説得する相手を間違える）
- **交点を絞りすぎる**（6軸全部固定すると該当者が数人になる）
- **平均値をそのまま対象に当てる**（年代別・平日休日別に分解する）
- **推論を反証せずに資料化する**（独り歩きして、以後の判断を歪める）
- **社会不安を煽る材料に使う**（心理は不安の解消に使う）
- **成果物に「あなたは◯◯タイプ」と書く**（プロファイルは内部判断に留める）
