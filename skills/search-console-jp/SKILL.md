# Search Console / Bing WMT 操作スキル（ブラウザ操作・安全境界つき）

「AI に届いたか」を**推測ではなく一次情報で**測れるようになったのが 2026 年の変化。このスキルはそこを取りに行く。

## この画面でできること・できないこと（安全境界の一覧）

| 操作 | 可否 | 根拠・条件 |
|---|---|---|
| 各種レポートの**閲覧・エクスポート** | ✅ 自律可 | 読み取り専用 |
| **生成AIパフォーマンスレポート**の取得 | ✅ 自律可 | 下記が本題 |
| URL 検査（インデックス状況の確認） | ✅ 自律可 | 確認のみ |
| **インデックス登録のリクエスト** | ⚠️ ゲート下で可 | 1URLずつ・少数に限る。大量申請は無意味かつ迷惑 |
| **sitemap の送信** | ⚠️ ゲート下で可 | 送信先URLを必ず読み上げて確認してから |
| **削除ツール（Removals）** | 🚫 **AI自律禁止** | 下記「削除ツールの正確な仕様」参照。人間の明示指示があるときのみ、指示されたURLだけ |
| **所有権の確認方法の変更・削除** | 🚫 禁止 | 自分を締め出す/他人に開ける事故 |
| ユーザーと権限の変更・招待 | 🚫 禁止 | |
| プロパティの削除 | 🚫 禁止 | 履歴データを失う |
| 国際化ターゲティング・クロール頻度等の設定変更 | 🚫 承認必須 | サイト全体の検索露出に波及 |
| **IndexNow（Bing）への URL 送信** | ⚠️ ゲート下で可 | 更新URLのみ。**Google は IndexNow に非対応**（2026年2月時点でも未対応）なので Google 側の代替にはならない |

## 削除ツールの正確な仕様（一次情報で確認済み）

AI は触らないが、ユーザーに説明する必要があるので正確に持っておく。

- **一時的なブロックのみ。期間は約6か月**。経過後は再び検索結果に表示されうる
- **恒久的に消すには**次のいずれかが要る: HTTP **404 または 410** を返す / パスワード保護 / **noindex** メタタグ / 一時ブロック後に解除→再ブロック
- **URL をブロックしてもクロールは継続する**
- **404・502・503 を返す URL はリクエストが失効する**
- 対象は **Google 検索のみ**。インターネット全体から消えるわけではない
- サイトを所有していないと使えない（所有者以外は「**古いコンテンツの更新ツール**」を使う。これは既に削除・更新済みのページの検索結果を更新するもの）
- 削除リクエストの履歴確認、**スニペット（ページ説明）の消去**、アダルトコンテンツとして報告された URL の確認も同じツール群にある

## 本題: AI 検索での露出を一次情報で測る

> **重要（一次情報での裏取り状況）**: 以下の生成AIレポート・Bing AIパフォーマンスレポートは、
> **Google / Microsoft の公式ヘルプでは確認できなかった**（Search Console の検索パフォーマンスヘルプには
> AI Overviews / AI Mode の記述が無く、公式ブログ記事も本文を取得できなかった）。
> 複数の独立した二次情報が具体的な日付つきで報じており実在の蓋然性は高いが、
> **仕様の細部（取れる指標・分離の有無・二重計上の扱い）は実機の画面で必ず確認すること。**
> 画面に無ければ「未提供」と記録する（FAIL にしない）。

### Google — 生成AIパフォーマンスレポート（2026年6月〜・**二次情報**）

- **2026-06-03 に提供開始、2026-06-23 に対象プロパティを拡大。** AI Overviews と AI Mode の**表示回数を通常検索から分離**して見られる。Discover の生成AI機能も別レポートがある
- 取れるのは **表示回数・ページ・国・デバイス**。**クリック・CTR・クエリはまだ出ない**
- これは新規に集めたデータではない。従来から全体のパフォーマンスレポートに**含まれていた**ものを切り出しただけで、全体レポート側でも引き続き計上される（**足し算しないこと** — 二重計上になる）
- ロールアウト中のため、**国・プロパティによってはレポートが出ない**。出ない場合は FAIL ではなく `未提供` と記録する

### Bing — AI パフォーマンスレポート（2026年2月〜・**二次情報**）

- **2026-02-09 に公開プレビューとして提供開始。** Microsoft Copilot・Bing の AI 要約・提携先での**引用（citation）**を追える
- **Bing のインデックスは ChatGPT search と Microsoft Copilot の取得層**になっている。**Bing に載っていないページは、Google でどれだけ順位が高くても、この2つの回答エンジンからは見えない**
- Google だけを見ていると、AI 露出の半分を落とす。**Bing WMT の登録は必須の初期設定として扱う**

### 通常レポートから読む傍証

生成AIレポートにクリックが無いため、**引用されたがクリックされていない**状態は次の乖離で読む:

- 表示回数が伸びている × CTR が下がっている → AI の回答内で引用され、クリックまで来ていない可能性
- これは**傍証であって証明ではない**。順位変動・季節性・SERP 変化でも同じ形になる。断定しないこと

## 週次で取るもの（`takumi.db` へ積む）

| 指標 | 取得元 | KPIツリーでの扱い |
|---|---|---|
| AI Overviews / AI Mode の表示回数 | GSC 生成AIレポート | **先行**（「AI経由の到達」ノードの露出側） |
| Copilot 等での引用 | Bing WMT AIパフォーマンス | 先行 |
| 全体の表示回数・クリック・CTR・平均掲載順位 | GSC 検索パフォーマンス | 先行 |
| 上位クエリと対応ページ | GSC | `takumi-campaign` のモダリティ設計へ返す |
| Bing のインデックス済みページ数 | Bing WMT | **AI から見えているかの前提条件**。急減は事故 |

## よくある事故と回避

| 事故 | 回避 |
|---|---|
| 削除ツールで消して戻せない/戻し方が分からない | AI は触らない。人間の明示指示のみ。**一時的措置であって恒久削除ではない**ことを必ず伝える |
| 生成AIレポートの数字を全体レポートに足した | **二重計上**。生成AI分は元から全体に含まれている |
| レポートが無いので FAIL にした | ロールアウト中。`未提供` と記録する |
| Google だけ見て AI 露出を判断した | Bing のインデックスが ChatGPT search / Copilot の取得層。Bing WMT を必ず併せて見る |
| CTR 低下を「AI に取られた」と断定した | 傍証にすぎない。順位変動・季節性を排除してから語る |
| 検索順位の改善を約束した | 順位は約束できない。**露出と流入の傾向**で語る |
