# 規模に合わせた戦略

**規模が違えば、正しい戦い方が逆になる。**

大手にとって正しい「幅広く・全方位に・同質化して潰す」は、規模の小さい側がやれば自殺行為。
**小さい側の唯一の勝ち筋は、範囲を狭めて、そこで1位になること。**

このスキルはランチェスター戦略を土台にする。**日本の事業者の99.7%は中小企業、84.5%は小規模事業者**
（中小企業庁）であり、**大多数は構造的に「弱者」の側**にいる。

> **ゼロ広告費との関係**: この理論の「兵力数」を、本プロダクトでは**投下できる時間**と読む。
> 広告費を使わない以上、金では兵力を増やせない。**時間は増やせないので、集中するしかない。**
> ここが `docs/parts/capacity-plan.md` と直結する。

## 0. 出典の扱い（先に読むこと）

**ランチェスター戦略の数値（シェア目標値・射程距離）は、原典に当たれていない。**
本スキルは解説サイトから取得しており、**田岡信夫の原著・B.O. Koopman の原論文は未取得**。
また**学術的な検証・批判も見つけられていない**（§出典欄に詳述）。

「シェアの目標値を**科学的に示した世界唯一の理論**」という宣伝文句が流通しているが、
**これを鵜呑みにしない。** 数値は**判断の目安**として使い、
**「この数字がこうだから正しい」という論拠には使わない。**

## 1. 二つの法則 — なぜ規模で正解が変わるのか

| 法則 | 式 | 成立する戦い方 |
|---|---|---|
| **第一法則** | 戦闘力 ＝ 武器効率 × **兵力数** | 一騎討ち・局地戦（狭い範囲・少数の競合） |
| **第二法則** | 戦闘力 ＝ 武器効率 × **兵力数の2乗** | 集団戦・確率戦（広域・多数の競合） |

**ここが核心**: 第二法則では**兵力の差が2乗で効く**。
広い市場で正面からぶつかれば、**兵力が2倍の相手には4倍の差がつく**。
規模の小さい側が広域戦に出るのは、**負け方を選んでいるのと同じ**。

**逆に第一法則の場では、兵力差はそのまま（2乗されない）**。
だから小さい側は「**第一法則が成立する場**」を選ぶ。

### 本プロダクトでの読み替え

| 理論 | 匠CMO での意味 |
|---|---|
| **兵力数** | **投下できる時間**（→ `docs/parts/capacity-plan.md`）。金では増やせない |
| **武器効率** | **非対称な強み**（→ `skills/winning-position-jp` §2）。差別化の質 |
| **局地戦** | 狭い領域・特定のクエリ・特定の場（→ `skills/seo-jp`「向かれていない読み手」） |
| **一騎討ち** | 競合が少ない問い・誰も答えていない問い |
| **接近戦** | 直接の関係（メール・コミュニティ・紹介 → `skills/referral-advocacy-jp`） |

**「広告費が効きにくい場所を選ぶ」（winning-position-jp）と、
「第一法則が成立する場を選ぶ」は、別のルートから同じ結論に着く。**

## 2. 弱者の戦略と強者の戦略

### 弱者の5大戦法（第一法則から導かれる）

| 戦法 | 中身 | 匠CMO での実装 |
|---|---|---|
| **局地戦** | 地域・領域を限定する | テーマを絞る・特定の検索意図に集中 |
| **一騎討ち戦** | 競合数の少ない戦いを選ぶ | 誰も答えていない問い（→ `seo-jp`） |
| **接近戦** | 顧客に近づく | メール・紹介・応対（→ `/メール`・`/エンゲージメント`） |
| **一点集中** | 資源を限定市場へ | 媒体もテーマも絞る（→ `capacity-plan.md`） |
| **陽動戦** | 相手の裏をかく | 大手が扱えない話題・言えない立場 |

### 強者の戦略（第二法則から導かれる）

**ミート戦略（同質化・模倣・二番手）**。相手が良い手を出したら**同じことをやって物量で潰す**。

**規模の小さい側にとって最大の脅威はこれ。** だから:

- **模倣されたら終わる差別化は、差別化ではない**（→ `winning-position-jp` の非対称性）
- **「真似するには相手が何かを失う」ものを選ぶ**（例: 弁護士事務所は「適法に働かせる手順」を
  丁寧には書けない → `skills/growth-teardown-jp` §3①）
- **目立ちすぎる前に地歩を固める**（規模が小さいうちは、大手に認識されないこと自体が防御）

## 3. 三つの結論

### (1) ナンバーワン主義

**1番と2番の差は、量の差ではなく質の差。** 記憶に残るのは1位だけ。
**「何の1位か」を言えないなら、まだ戦略が無い。**

### (2) 足下の敵攻撃の原則

**自社より1ランク下を狙う。** 1位なら2位を、3位なら4位を。

**規模の小さい側が、いきなり首位に挑まない。**
届く相手から順に取るほうが、同じ時間で得られるものが大きい。

### (3) 一点集中主義

**全体で勝てないなら、勝てる範囲まで細分化して、そこで1位を取る。**

細分化の軸: **地域 / 客層 / 用途 / 商品 / 販売経路 / 時期**。

**細分化は「諦め」ではなく「勝ち方の設計」。**
1位を取った範囲が、次の範囲へ進む足場になる。

## 4. シェアの目標値（7段階）

| 数値 | 名称 | 意味 |
|---|---|---|
| **73.9%** | 上限目標値 | 独占的。地位が圧倒的に安定する |
| **41.7%** | 安定目標値 | 1位として安定する。事実上のナンバーワン |
| **26.1%** | **下限目標値** | **1位の最低条件。下回ると1位でも安定しない** |
| **19.3%** | 上位目標値 | 上位グループに入る |
| **10.9%** | 影響目標値 | 市場全体に影響を与え始める足がかり |
| **6.8%** | 存在目標値 | 存在を認められ始める |
| **2.8%** | 拠点目標値 | 拠点として認識され始める |

### 使い方（機械で確かめる）

```python
from takumi.domain.market_share import LanchesterMode, MarketShare

ms = MarketShare("名古屋市の個人向けピアノ教室（月謝制）", 0.30)
ms.current_stage()   # (0.261, '下限目標値', ...)
ms.next_target()     # (0.417, '安定目標値', ...)
ms.verdict(leader_share=0.45, mode=LanchesterMode.FIRST_LAW)
```

**`MarketShare` は市場の定義（分母）が空だと `ValueError` になる。**
これは実装の都合ではない — **分母を決めなければ、範囲を狭めていくらでも「1位」を作れる**から。
自己満足で済むうちはよいが、**対外的に「No.1」と表示すれば根拠を問われる**
（→ `skills/ad-compliance-jp`）。

**シェアが推定できないことは多い。** そのときは「推定不能」と書き、
**代わりに観測できるもの**（そのクエリでの露出、特定コミュニティでの言及、紹介の発生数）で
1位かどうかを見る。**推測の数字を書かない。**

## 5. 射程距離 — 追うべきか、場所を変えるべきか

| 場 | 逆転困難になる差 |
|---|---|
| **第一法則が働く場**（局地戦・一騎討ち・2社競合） | **3倍** |
| **第二法則が働く場**（広域戦・多数競合） | **√3倍（約1.7倍）** |

**差がこれを超えていたら、正面から追わない。**
やることは「もっと頑張る」ではなく、**市場を細分化して、1位を取れる範囲を作り直すこと**。

```python
ms.is_within_striking_distance(leader_share=0.40, mode=LanchesterMode.FIRST_LAW)
```

**自社シェアが0のとき、倍率は計算されない（`None`）。**
「差が無限大」ではなく**判定不能**として扱う（→ 他のドメインと同じ原則）。

## 6. 規模別の型

**同じ「弱者の戦略」でも、規模で実行の形が変わる。**

### 個人・一人（最も制約が強い）

- **兵力＝自分の時間だけ。** 増やせない。**外注も管理コストがかかる**
- **1媒体・1テーマ・1客層から始める**（同時に複数を回すと全部が中途半端になる）
- **接近戦が最も効く** — 大手が採算に合わずできない、**一人ひとりへの対応**が武器
- **属人性は弱みではなく武器**（→ `growth-teardown-jp` の「当事者性が信頼の担保」）
- **落とし穴**: 積み上がらない仕事（都度対応）で時間が埋まり、資産が増えない。
  **週の一定割合を「積み上がる仕事」に固定する**（→ `winning-position-jp` §4）

### 少人数（2〜10人程度）

- **1人1領域で1位を取る**（全員で同じことをやらない）
- **役割の重複を避ける** — 兵力が分散すると、どの領域でも1位に届かない
- **属人性から型へ**（→ `breakout-content-jp` §6 の「2回再現したら型にする」）
- **落とし穴**: 人が増えた分だけ手を広げてしまう。**増えた兵力は、既に1位の領域の深耕に使う**

### 中小（10人〜）

- **1位の領域を足場に、隣接領域へ**（飛び地に出ない）
- **足下の敵攻撃**（1ランク下を狙う）が現実的に効く規模
- **落とし穴**: 全方位に張れる錯覚。**まだ第二法則の土俵には出られない**

### 競合が大手のとき（相手が強者）

- **相手のミート戦略を前提に置く。** 真似されて終わる差別化を選ばない
- **大手が採算に合わない領域**を選ぶ（小さすぎる・手間がかかる・説明が要る）
- **大手が立場上言えないこと**を言う（→ 非対称）
- **正面から比較しない**（比較広告は景表法の対象 → `skills/ad-compliance-jp`）

## 7. 実際の手順

1. **自社の規模と立場を確定する**（弱者か強者か。**ほぼ常に弱者**）
2. **今の市場の定義を書く**（分母。地域 × 客層 × 用途 × 期間）
3. **その分母でのシェアと1位との差を出す**（推定不能なら「不能」と書く）
4. **射程距離を判定する**（超えていたら §8 へ）
5. **超えていなければ、足下の敵から取る**
6. **超えていたら、1位を取れるまで細分化する**（§8）
7. **決めた1点に、時間を集中する**（→ `capacity-plan.md`。**他を落とす**）
8. **1位を取ったら、次の隣接領域へ**（飛び地に行かない）

## 8. 細分化の作法 — どこまで狭めるか

**「1位を取れるまで狭める」が原則。ただし狭めすぎると事業にならない。**

**止める条件**（どちらかを満たしたら、それ以上狭めない）:

- **その範囲の需要が、事業として成立する規模を下回った**
  （→ `skills/business-model-jp` の損益分岐点で確かめる）
- **顧客がその括りを理解できない**（説明に3段落要る括りは成立しない
  → `winning-position-jp` §3）

**狭めた範囲は必ず1文で言えること。** 言えないなら、それは細分化ではなく言い訳。

## 9. よくある失敗

- **規模を確かめずに一般論の戦略を当てる**（大手の正解は小さい側の自殺行為）
- **広い市場で正面からぶつかる**（第二法則では兵力差が2乗で効く）
- **分母を決めずに「1位」を名乗る**（対外的に言えば No.1 表示の根拠を問われる）
- **模倣されたら終わる差別化を選ぶ**（強者のミート戦略で潰される）
- **射程外の相手を正面から追う**（「もっと頑張る」で解決しない。場所を変える）
- **いきなり首位に挑む**（足下の敵＝1ランク下から取る）
- **細分化を「諦め」だと思う**（勝ち方の設計であり、次への足場）
- **狭めすぎて事業が成立しない**（§8 の止める条件）
- **一点集中を決めたのに、他を落とさない**（集中とは捨てること → `capacity-plan.md`）
- **兵力＝金だと思う**（ゼロ広告費では**時間が兵力**。だから集中しか手が無い）
- **シェア目標値を「科学的根拠」として引用する**（→ §0・出典欄）
