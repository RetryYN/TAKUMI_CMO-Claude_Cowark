# セールスライティング

**対象領域: 無形商材（サービス・SaaS・コンサル・制作・教育など、実物のないもの）**

無形サービスの価値を伝え、見込み客の行動（問い合わせ・資料請求・申し込み）を促す文章技法。

> **ゼロ広告費の前提**: ここで書くのはすべて**オーガニックな接点**の文章 — 自社LP・オウンドメディア・
> メール・提案書。有料広告のクリエイティブは扱わない。「広告で連れてきて売る」のではなく、
> 「検索・SNS・紹介で辿り着いた人に、読んで納得してもらう」ための文章を書く。

## 無形商材の最大の課題

> **見えない、触れない、試せない → 信頼がすべて**

| | 有形商材 | 無形商材 |
|---|---|---|
| 購入前 | 実物を見れる | 見えない |
| 判断基準 | スペック比較 | 信頼・実績・具体性 |
| 効果実感 | 即時 | 時間がかかる |
| 失敗リスク | 返品できる | 支払った時間が戻らない |

→ **だから「信頼」と「具体性」で売る。** 抽象的な形容詞（最適な・充実した・きめ細かい）は
無形商材では何も伝えない。**検証できる形にした事実**だけが信頼を作る。

## セールスフォーミュラ

### PAS（Problem → Agitate → Solve）

痛みが自覚されている市場で使う。**Agitate は事実の提示に留める** — 恐怖を煽ったら
session-rules (3) 違反であり、ad-compliance-jp の対象にもなる。

```markdown
【Problem: 痛みを言語化】
「記事を書いても書いても、問い合わせに繋がらない。」

【Agitate: 痛みの構造を示す（煽らない・事実で）】
「本数を増やしても伸びないのは、読者の検索意図と記事の答えがずれているからです。
 ずれたまま量産すると、書くほど平均掲載順位が下がることさえあります。」

【Solve: 解決策】
「[サービス名]は、公開前に検索意図との一致を診断します。」
```

### BAB（Before → After → Bridge）

痛みが自覚されていない／言語化されていない市場で使う。

```markdown
【Before: 現状】
「記事の企画会議に毎週2時間。決まらないまま解散し、結局書ける人が書ける物を書く。」

【After: 理想】
「企画は15分で決まる。何を書くかではなく、どう良くするかを話す会議になる。」

【Bridge: 橋渡し】
「[サービス名]が、検索データから企画候補を先に並べます。」
```

## 提案書テンプレート

```markdown
## 1. エグゼクティブサマリー
[1段落: 何を提案し、どんな成果が見込めるか]

## 2. 貴社の課題（ヒアリング内容の整理）
- 課題1: [具体的に。数字で]
- 課題2: [具体的に。数字で]
※ヒアリングしていないことを推測で書かない。埋まらない項目は「未確認」と書く

## 3. 解決策
### サービス概要
[何をどう提供するか]

### なぜ当社か
| | 当社 | 一般的な選択肢 |
|---|---|---|
| [比較軸1] | [事実] | [事実] |
| [比較軸2] | [事実] | [事実] |
※比較表で他社を誤認させる書き方は景表法（比較広告）の対象。ad-compliance-jp を通す

### 期待効果
- [指標]: 現状[X] → [Y]（**前提と根拠を併記**。根拠がなければ「仮」と明示）

## 4. 料金体系
[何にいくらかかるか。追加費用の発生条件も書く]

## 5. 導入事例
### [事例名]
- 課題: [Before]
- 施策: [何をしたか]
- 結果: [数字で]
※実在する事例のみ。**無い場合は事例セクションごと落とす**（創作は即アウト）

## 6. 次のステップ
1. [具体的な行動・期限つき]
```

## LP構成（無形サービス）

```
1. ヘッド: 訪問者の課題に共感するキャッチ（copywriting）
2. 課題提示: 「こんな状態ではありませんか」3つ
3. 解決策: サービスの仕組み（図解。文字だけで説明しない）
4. 実績: 検証できる数字（あるものだけ）
5. 事例: Before/After（2〜3件）
6. 料金: 何にいくらかかるかを隠さない
7. FAQ: 買わない理由の上位3つに正面から答える
8. CTA: 次の一歩を1つだけ（複数のCTAは迷いを生む → cro-jp）
```

ブロック配置の根拠は `skills/web-design`（LP構成）、心理根拠は `skills/psych-ux-jp`、
訴求フレームの選択は `skills/psych-nudge-jp` に従う。

## 信頼構築パーツ（無形商材の生命線）

| パーツ | 使い方 | 禁止 |
|---|---|---|
| 数字実績 | 「導入◯社・継続率◯%」— 集計期間と母数を併記 | 母数を書かない％ |
| 顧客の声 | 実名・所属・具体的な変化。**掲載許諾を取る** | 創作・匿名の絶賛 |
| Before/After | 期間と条件を明記 | 条件を隠した劇的比較 |
| リスクリバーサル | 返金・解約条件を正確に | 適用されない保証の示唆 |
| プロセス開示 | やり方を公開する（ブラックボックスにしない） | — |

**体験談・口コミを載せるときはステマ規制と打消し表示の対象**（`skills/ad-compliance-jp` 必須）。
