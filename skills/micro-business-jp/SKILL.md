# マイクロビジネスとトップニッチ

**一人〜数人の事業には、大きい事業とは別の失敗の型がある。**

売上が伸びても**自分の時間が上限**になり、忙しくなるほど**新しいことができなくなる**。
そして**自分が止まると全部が止まる**。

**規模が小さいことは弱みではない。** 大手が採算に合わずできないことができる。
ただし**構造を設計しないと、時間を切り売りするだけで終わる**。

> **`skills/scale-strategy-jp` との違い**: あちらは「**どこまで狭めるか**」を判定する
> （射程距離・細分化）。ここは「**狭めた先でどう事業として成立させるか**」を扱う。
> **順番は scale-strategy → micro-business。**

## 0. 最初に確かめる3つ

| 問い | 「いいえ」なら |
|---|---|
| **売上が伸びたとき、自分の時間以外に増やせるものがあるか** | §2（レバレッジ）へ |
| **自分が2週間止まっても事業が続くか** | §5（属人性）へ |
| **狭めた領域で、1位だと言えるか** | → `skills/scale-strategy-jp` に戻る |

**3つとも「いいえ」なら、集客より先に構造を直す。**
集客を増やしても、**時間の上限に早く到達するだけ**になる。

## 1. トップニッチ — 狭い領域で1位を取り、そこから広げる

### ニッチの選び方（4条件すべて）

| 条件 | 確かめ方 |
|---|---|
| **1位を取れる狭さか** | → `skills/scale-strategy-jp`（射程距離・細分化の止める条件） |
| **事業として成立する規模か** | → `skills/business-model-jp`（損益分岐点） |
| **自分に非対称な強みがあるか** | → `skills/winning-position-jp` §2（真似すると相手が何を失うか） |
| **顧客がその括りを理解できるか** | 説明に3段落要る括りは成立しない |

**「好きだから」で選ばない。** 好きは続ける力にはなるが、**選ぶ基準にはならない**。
上の4条件を通ったうえで好きなら、それは強い。

### ニッチの広げ方（順番を守る）

```
① 1つのニッチで1位を取る（ここが足場）
     ↓ 足場ができてから
② 隣接へ広げる — **客層は同じで用途を変える** or **用途は同じで客層を変える**
     ↓
③ 2つ目のニッチでも1位を取る
```

**同時に2つ広げない。** 兵力（＝時間）が分散すると、**どちらでも1位に届かない**。
**飛び地に行かない**（客層も用途も違う領域は、実質ゼロからのやり直し）。

**「隣接かどうか」の判定**: **既存顧客に、そのまま紹介できるか**。
できないなら隣接ではない（→ `skills/referral-advocacy-jp`）。

## 2. レバレッジ — 時間を売る構造から抜ける

**一人の売上は「時間 × 単価」で頭打ちになる。** 抜け道は4つしかない。

| 手 | 何をするか | 注意 |
|---|---|---|
| **① 単価を上げる** | 同じ時間で得るものを増やす | **最初に検討する**（→ `skills/offer-design-jp` §6） |
| **② 資産にする** | 1回作って何度も使う（記事・テンプレ・動画・教材） | **積み上がるが、当たるまで時間がかかる** |
| **③ 仕組みにする** | 手順を型にし、繰り返しを自動化・省力化 | 型にできるのは**2回再現できたものだけ** |
| **④ 人に任せる** | 外注・採用 | **管理コストが増える**。②③の前にやると破綻しやすい |

**順番は ① → ② → ③ → ④。**
**単価を上げずに人を増やすと、忙しさだけが増える。**

### 資産と受託の比率を決める

**都度対応（受託）は現金になるが積み上がらない。資産は積み上がるが今月の現金にならない。**

- **週の一定割合を「積み上がる仕事」に固定する**（例: 2割）。
  空いた時間でやろうとすると、**永久に空かない**
- 比率は `docs/parts/capacity-plan.md` の埋まり具合で管理する
- **受託が埋まりきった状態を「順調」と呼ばない。** それは**上限に張り付いた状態**

## 3. 商品の階段 — 入口から本体、そして継続へ

**一人ビジネスで最も多い失敗は「本体商品しか無い」こと。**
検討期間が長い相手に、いきなり本体は売れない。

| 段 | 役割 | 設計の要点 |
|---|---|---|
| **入口** | 相手のリスクをほぼゼロにする | **入口だけで完結した価値**を持たせる（→ `skills/offer-design-jp` §4） |
| **本体** | 主たる収益 | ここが**非対称な強み**を最も使う場所 |
| **継続** | 積み上がる収益 | 続ける理由を設計する（→ `/リテンション`） |

**階段を作るときの禁止**: **入口を安くするために本体の価値を薄める**こと。
入口は「小さいが完結したもの」であって、**本体の劣化版ではない**。

**継続が作れない商材もある。** その場合は**紹介**を継続の代わりに置く
（→ `skills/referral-advocacy-jp` — ゼロ広告費で唯一 複利で増える経路）。

## 4. 単価 — 安すぎる値付けが一番多い失敗

**一人ビジネスの値付けは、たいてい安すぎる。** 理由は「自分の時間を原価に入れていない」から。

```python
from takumi.domain.unit_economics import OrganicAcquisitionCost
# 提案・打ち合わせ・修正対応まで含めた実時間で見る
OrganicAcquisitionCost(hours_spent=40, hourly_rate_yen=5_000, customers_acquired=2).verdict(
    gross_profit_per_customer_yen=30_000
)
```

**「見えない時間」を必ず入れる**: 提案・見積・打ち合わせ・修正・請求・入金確認。
**これらを数えないと、時給が実際の半分以下になっていることに気づけない。**

**値上げの順番**（→ `skills/offer-design-jp` §6）:

1. **新規から先に上げる**（既存は据置期間を設ける）
2. **上げる理由を、提供内容の変化とセットで示す**
3. **下げるのは片道切符**（戻せないなら下げない）

## 5. 属人性 — 武器であり、同時に上限

**個人の名前で戦うのは、小さい側の正当な武器。**
大手は「担当者が誰か」を売りにできない。**当事者性は真似できない**
（→ `skills/growth-teardown-jp` §4(2)「何で信じてもらうか」）。

**ただし属人性は、そのまま事業の上限になる。**

| 局面 | 属人性の扱い |
|---|---|
| **立ち上げ〜1位づくり** | **前面に出す**（信頼の担保が他に無い） |
| **広げる段階** | **型に移す**（2回再現できた手順から順に） |
| **休む・引き継ぐ** | **記録が資産**（判断基準を残す。本人の頭の中は資産ではない） |

**「自分が2週間止まっても続くか」を年1回確かめる。**
続かないなら、**それは事業ではなく仕事**である（どちらを選ぶかは本人の判断だが、
**選んでいる自覚が要る**）。

## 6. 受注する側の法的な足場（日本・2024年11月1日施行）

**一人で受託する側には、法律上の保護がある。** 知らないまま不利な取引を続けない。

**フリーランス・事業者間取引適正化等法**（特定受託事業者に係る取引の適正化等に関する法律）。

**「特定受託事業者」の定義**（法の対象）:

> 「個人であって、従業員を使用しないもの」
> 「法人であって、一の代表者以外に他の役員がなく、かつ、従業員を使用しないもの」

**発注事業者の義務**（＝受注側が求めてよいこと）:

- **取引条件の明示**: 「①業務委託事業者及び特定受託事業者の名称②業務委託をした日③給付・役務の内容
  ④給付・役務提供の期日⑤給付・役務提供の場所⑥報酬の額及び支払期日」
- **報酬支払期日**: 「給付を受領した日から起算して**６０日以内**のできる限り短い期間内で
  報酬の支払期日を定めなければならない」
- **7つの禁止行為**: 受領拒否／報酬減額／返品／買いたたき／購入・利用強制／
  不当な経済上の利益提供要請／不当な給付内容変更・やり直し
- **募集情報の的確表示**: 「虚偽の表示や誤解を生じさせる表示の禁止」
- **育児介護等への配慮**／**ハラスメント対策**（相談窓口の設置・周知等）
- **中途解除の予告**: 「**６か月以上**の期間行う業務委託に係る契約を解除する場合、
  解除日の少なくとも**３０日前**までに予告」

**発注する側に回るときも同じ義務を負う。** 外注を使い始めた時点で、
**自分が発注事業者になる**（→ §2 ④）。

**個別の紛争は AI の領域ではない。** 事実関係を整理したうえで、
**公正取引委員会・厚生労働省の相談窓口、または弁護士へ**。

## 7. 一人・少人数で起きやすい失敗

- **全部やる**（媒体も商品も客層も広げ、どれも1位に届かない）
- **単価が安すぎる**（見えない時間を原価に入れていない）
- **受託で埋まりきった状態を「順調」と呼ぶ**（上限に張り付いている）
- **積み上がる仕事を「空いたらやる」にする**（永久に空かない。**割合で固定する**）
- **本体商品しか無い**（検討期間が長い相手に届かない）
- **入口を本体の劣化版にする**（安いだけで完結した価値が無い）
- **単価を上げずに人を増やす**（忙しさだけが増える）
- **属人性を型に移さない**（休めない・引き継げない・広げられない）
- **好きだからでニッチを選ぶ**（選ぶ基準にはならない。4条件を通してから）
- **同時に2つ広げる／飛び地に行く**（既存顧客に紹介できないなら隣接ではない）
- **取引条件を書面で明示させない**（法律上、求めてよい）
