# 日本の表示規制チェックスキル

生成した表現が行政処分リスクを持たないかの公開前検査。**「広告を出さない＝法規の対象外」ではない** —
景表法・ステマ規制は自社サイト・記事・SNS投稿にも等しくかかる（対象は「表示」であって出稿ではない）。
**これは品質チェックではなく法的ゲート** — 該当項目は「直すか、根拠を用意するか、人間の法務確認に回すか、
**止めて人間に返すか**」のいずれかで必ず処理する。

**射程の線引き（重要）: 薬機法（旧・薬事法）と医療広告規制は、本プロダクトの対象外。**
検知はするが**可否は判断せず、書き換えもせず、人間・専門家に返す**（§3・§7）。
表現の可否が製品の分類や事案ごとの評価に依存する領域で、
**AI が「これなら通る」を出した時点で、判断したことになってしまう**ため。

**もう1つの原則: 法規で許されることと、プラットフォームで許されることは別。**
ステマ規制は「事業者の関与を表示すれば可」というルールだが、
たとえば Google は対価と引き換えの口コミそのものを禁止している。
**法規チェックを通しても、出す先の規約を別に確かめる**（→ 各媒体パック・`skills/local-seo-jp`）。

## 0. 適用判定 — 自分に効く法域を先に絞る

**全部を毎回見ない。該当しない節は飛ばし、該当する節は必ず通す。**
判定はブランドの事業内容で決まるので、**ブランド登録時に一度決めて `brand.yaml` に書いておく**
（毎回の推測をやめる → `skills/brand-guideline-jp`）。

| 節 | 法域 | 適用されるブランド |
|---|---|---|
| §1 | 景品表示法 | **全ブランド**（例外なし） |
| §2 | ステマ規制 | **全ブランド**（第三者に書いてもらう可能性がある限り） |
| §3 | 薬機法（旧・薬事法） | 医薬品・医薬部外品・化粧品・医療機器・美容、および効能効果を示唆する食品・雑貨。**対象外＝検知して停止し、人間へ返す** |
| §4 | 健康増進法 | **食品として販売する物**を扱う（健康食品を含む） |
| §5 | 特定商取引法（通信販売） | **通信販売を行う**（EC・オンライン申込・定期購入・メール広告） |
| §6 | 職業安定法 | 自社の求人・採用情報を出す |
| §7 | 医療広告規制 | 病院・診療所・歯科（**別法体系。AI はここで止める**） |

## 1. 景品表示法（全ブランドに適用）

| 検査項目 | ルール |
|---|---|
| No.1・最大級表現（「No.1」「日本一」「業界最大」「顧客満足度1位」） | **客観的調査の裏付け+調査機関・調査時期・出典の併記が必須**。イメージ調査ベースのNo.1は措置命令事例あり。根拠が確認できなければ使用不可。**そもそも「何の中で1位か（分母）」を書けないなら扱わない**（→ `takumi/domain/market_share.py` が分母の無いシェアを拒否する） |
| 優良誤認 | 実際より著しく優れていると誤認させる表現の禁止（効果の断定・誇張、加工画像による性能偽装） |
| 有利誤認 | 二重価格（「通常◯円→今だけ◯円」）は通常価格の販売実績が必要。「期間限定」の常態化は不可 |
| 打消し表示 | 「※個人の感想です」等は本文と同等の視認性が必要（極小文字での免責は無効） |
| 景品・特典の金額 | 上限は**計算できる**ので文章で済ませない（→ `takumi/domain/premium.py`。種別の判断は人間） |

**令和5年改正法が令和6年10月1日に施行**され、確約手続の導入・課徴金制度の見直し・
直罰規定の導入が行われている。**内容の原文は未取得**（下記「出典」参照）だが、
**「行政処分の前段階が増えた」のではなく「制裁の選択肢が増えた」と読む**のが安全側。
表現の根拠を残す運用（誰が・いつ・何を根拠に承認したか）を強く推奨する。

## 2. ステマ規制（2023年10月〜、処分対象は広告主企業）

- 事業者が関与する表示（インフルエンサー投稿・レビュー依頼・ギフティング）には
  **「#PR」「#広告」等の明示が必須**
- 第三者を装った自作レビュー・依頼レビューは不当表示
- 生成する投稿がタイアップ/依頼投稿の文脈なら、PR表記をデフォルトで入れる（外すのは人間の判断のみ）
- **役員・従業員・取引先に好意的投稿を依頼しない**（利害関係者の投稿は、表示の有無以前に信用を壊す）
- **表示すればよい、で止まらない。** 出す先のプラットフォームが対価つき投稿自体を禁じていることがある
  （Google の口コミが典型 → `skills/local-seo-jp` §3）

## 3. 薬機法（旧・薬事法）— **対象外。検知して止め、人間に返す**

**医薬品・医薬部外品・化粧品・医療機器・再生医療等製品、および健康食品の効能効果の表現は、
本プロダクトの射程外とする。** 表現の可否が「その製品が何に分類されるか」に依存し、
分類そのものが専門的な判断だからで、AI が書き換えて通してよい領域ではない。

**やること（検知と停止まで）:**

1. **該当領域かを判定する** — 医薬品・医薬部外品・化粧品・医療機器・再生医療等製品を扱う、
   または食品・雑貨に**身体への効能効果を示唆する表現**がある
2. 効能効果・身体の変化を示唆する表現を**すべて列挙する**
   （「治る」「痩せる」「若返る」「シミが消える」「免疫力が上がる」等）
3. **書き換えない。** 「うるおいを与える」等の許容表現へ言い換えて納品しない
   — **通してよい範囲を AI が決めた**ことになる
4. 成果物に「**薬機法領域。本プロダクトでは可否を判断しない。掲載前に人間・専門家の確認が必要**」
   と明記して返す

**§4（健康増進法）は対象外にしない。** 所管も条文も別で、
**「食品の健康保持増進効果について著しく誤認させる表示」**という消費者庁側のルールは引き続き検査する。
ただし**個別の効能表現が薬機法上どう扱われるかには踏み込まない**（そこが §3 の停止範囲）。

## 4. 健康増進法 — 誇大表示の禁止（食品を扱う場合）

**§3（対象外）とは所管も条文も別で、こちらは検査する。**
薬機法上どう扱われるかに踏み込まなくても、**食品の健康保持増進効果の表示**というだけでこの条文の射程に入る。
健康増進法第65条第1項:

> 何人も、食品として販売に供する物に関して広告その他の表示をするときは、
> 健康の保持増進の効果その他内閣府令で定める事項（健康保持増進効果という）について、
> **著しく事実に相違する表示をし、又は著しく人を誤認させるような表示をしてはならない。**

読み違えやすい点を3つ:

1. **「何人も」** — 販売者に限らない。**アフィリエイター・記事の書き手・SNS の投稿者も対象になりうる**。
   自社商品でなくても、食品の効果を書けばこの条文の射程に入る
2. **対象は「食品として販売に供する物」** — いわゆる健康食品・サプリメントを含む
3. **景表法とは別** — 景表法の優良誤認をクリアしても、こちらで落ちることがある

検査の実務: 食品を扱うブランドでは、**「体調が良くなる」「免疫力が上がる」「痩せる」の類の表現を
すべて列挙して人間に返す**。書き換えで逃げず、**根拠（表示制度上の位置づけ）を確認してもらう**。

## 5. 特定商取引法 — 通信販売（オンラインで売る／メール広告を送る場合）

**「広告」ではなく「取引の表示」の規制なので、LP・申込ページ・メールがそのまま対象になる。**

| 項目 | ルール |
|---|---|
| **広告の表示事項**（法第11条） | 販売価格（**送料についても表示が必要**）、代金の支払時期・方法、商品の引渡時期 等。広告スペースに制約がある場合、消費者の請求により「遅滞なく」情報提供できる措置があれば一部省略可 |
| **誇大広告等の禁止**（法第12条） | 「著しく事実に相違する表示」「実際のものよりも著しく優良であり、若しくは有利であると人を誤認させるような表示」の禁止 |
| **電子メール広告のオプトイン規制**（法第12条の3・4） | **消費者があらかじめ承諾しない限り、電子メール広告の送信は原則禁止。承諾記録は3年間保存**が必要 |
| **返品制度**（法第15条の3） | 商品の引渡しを受けた日から数えて**8日以内**であれば撤回・解除でき、消費者の送料負担で返品できる。**事業者が広告であらかじめ特約を表示していた場合は特約による** |
| **最終確認画面** | 分量、販売価格、支払時期・方法、引渡時期、返品条件などの表示が必須 |

**匠CMO の運用に直結する2点:**

- **/メール で一斉配信する前に、承諾（オプトイン）の有無と記録の所在を確認する。**
  リストの出所が言えないなら送らない。**同じ趣旨のオプトイン規制は特定電子メール法にもある**（→ 出典）
- **返品特約を「書いてあるからOK」で流さない。** 特約は**広告にあらかじめ表示していた場合**に効く。
  申込直前だけに置いた特約は前提を満たさない可能性がある → 人間の確認へ

**定期購入（サブスクリプション）は最終確認画面の要求が具体的**なので、
オファー設計の段階で `skills/offer-design-jp` §7 と突き合わせる。

## 6. 職業安定法（**求人系のコンテンツを扱うブランドの場合のみ**）

自社の採用ページや求人情報を出すブランドを担当するときだけ適用する。該当しなければこの節は飛ばしてよい。

- **的確表示義務**: 虚偽・誤解を生む表示の禁止、情報を正確かつ最新に保つ義務
- **労働条件の明示**: 賃金（幅がある場合は幅と根拠）・勤務地・業務内容・雇用形態・試用期間の記載
- 「みなし残業」を含む場合は時間数と超過分の扱いを明示
- モデル年収を出す場合は前提（年次・実績）を併記。最高値だけの提示は誇張リスク
- 実在しない好条件求人（釣り求人）は禁止

## 7. 医療広告規制（病院・診療所・歯科）— **AI はここで止める**

**医療機関の広告は、景表法や薬機法とは別の体系で規制されている。**
根拠は医療法と、厚生労働省の指針「医業若しくは歯科医業又は病院若しくは診療所に関する広告等に関する指針」
（医療広告ガイドライン）。**ウェブサイトも規制の対象になりうる。**

このスキルは医療広告ガイドラインの内容を保持していない（**原文未取得** → 出典）。
したがって医療機関ブランドでは:

1. **AI は表現の可否を判断しない。** 「たぶん大丈夫」を出さない
2. **体験談・術前術後（ビフォーアフター）の写真は、原則禁止として扱う。**
   例外（限定解除）の要件は事案ごとの評価を含むため、**人間・専門家の確認に回す**
3. 生成物には「**医療広告規制の対象。掲載前に医療機関側の確認が必要**」と明記して返す
4. 美容医療・自由診療は特に厳しく見られている領域として扱う

**同じ扱いをする隣接領域**: §3（薬機法領域）、弁護士・税理士等の士業広告（各会の規程）、
金融商品（金商法の広告規制）。**このスキルの射程外であることを明示して人間に返す。**

## 8. 実行手順

1. **§0 の適用判定**で、このブランドに効く節を確定する（`brand.yaml` に記録があればそれに従う）
2. 成果物のコピーを走査し、該当節のパターンを列挙する
3. 各該当項目を**4分類**で処理:
   - **修正**: 表現の書き換えで解消できるもの（断定→範囲内表現等）
   - **根拠要求**: `[要根拠: ◯◯]` を付けてユーザーに事実確認を求めるもの（No.1・実績数値・価格・承諾記録）
   - **法務確認**: 健康増進法該当・際どい比較広告は「人間の法務確認推奨」と明記
   - **停止**: **§3 該当（薬機法領域）と §7 該当（医療）は本プロダクトの対象外。
     書き換えで通さず、該当表現を列挙して人間・専門家に返す**
4. **出す先の規約を別に確かめる**（プラットフォームのポリシーは法規と独立に効く）
5. チェック結果を成果物の末尾に
   「法規チェック: 適用[§1 §2 §5] / 問題なし / 修正◯件 / 要確認◯件 / 停止◯件」として1行添付

## 免責

このチェックは網羅的な法務レビューの代替ではない。最終判断は人間（必要に応じて専門家）が行うこと。
**通ったことは適法の保証ではない。**

- **景品表示法・職業安定法の各条文**: §1・§2・§6 は本プロダクトの既存記述を引き継いでおり、
  **本スキルでは条文の原文照合をしていない**。金額・数値を伴う判断には使わない
- **§3（薬機法）は条文も運用基準も保持していない。** 対象外としたのは
  「原文が取れなかったから」ではなく、**製品の分類と事案ごとの評価に依存する領域で、
  AI が可否を出すこと自体が誤り**だと判断したため。**原文を取得しても §3 は開かない**
