# スキル接続図（`skills/` 42本 — 接続の正本）

**スキルは単体では効かない。** 1本のスキルが答えを出す場面はほとんど無く、
実務では「前に決まっているべきこと」と「決めた後に進む先」が必ずある。
そこがつながっていないと、**開いたスキルの中だけで完結した、前提の無い答え**が出る。

このファイルは、42本のスキルが**どこから来てどこへ行くか**の正本。
各 `SKILL.md` の `## 接続` セクションはここの写しであり、**両者が食い違ったらここが正しい**。

## なぜ作ったか（2026-07-26 の実測）

スキル間の参照を機械で数えたところ、網に**穴が2種類**あった。

| 症状 | 実測 | 何が起きるか |
|---|---|---|
| **孤島**（どのスキルからも指されない） | `market-analysis-jp`・`micro-business-jp` の2本 | 手順書からは届くが、**スキルを開いた人はそこへ辿り着けない** |
| **行き止まり**（他スキルへ一切つながらない） | `business-writing`・`psych-target-jp`・`search-console-jp` の3本 | 開いたら終わり。次に何をするかが本人任せになる |

原因ははっきりしていて、**新しいスキルを足すとき、兄弟スキル側を更新していなかった**。
新設スキルは既存の網へ向けて外向きのリンクを張るが、既存側からの張り返しが無い。
実際 `channel-planning-jp` は出13・入1、`social-insight-jp` は出11・入1、`micro-business-jp` は出6・**入0** だった。

**文章の規約では再発する**ので、`scripts/lint.py` が機械で止める（下記「不変条件」）。

## 層 — 匠の∞ループのどこにいるか

上流（戦略）から下流（実行）へ下り、計測で上流へ戻る。**層をまたぐ矢印が「接続」**。

```
A. 環境と人を知る ─→ B. 勝ち筋を決める ─→ C. 計画する ─→ D. 作る ─→ F. 出す前の関門 ─→ 公開
        ↑                                                    ↑
        └────────────── G. 測る ←───────────────┘   E. 効かせる（D を支える）
```

`cro-jp` で改善に変え、`customer-analytics-jp`（A層）へ戻す。**∞の上り。**

## 接続の不変条件（`scripts/lint.py` が機械で止める）

1. **すべての `SKILL.md` に `## 接続` セクションがある**
2. **行き止まりを作らない** — 各スキルは他スキルへ **2本以上**リンクする
3. **孤島を作らない** — 各スキルは他スキルから **1本以上**指される
4. **デッドリンクを作らない** — `skills/<name>` 参照は実在するスキルを指す
5. **この地図に全スキルが載っている** — 載っていないスキルがあれば落ちる

**2 と 3 が本体。** スキルを新設したとき、外向きのリンクは自然に書くが、
**既存スキル側からの張り返しは意識しないと必ず忘れる**。3 がそれを強制する。

## スキルを1本足すときの手順

1. `skills/<name>/SKILL.md` を書く（frontmatter の `description` に Use when / Not for）
2. **`## 接続` を書く**（前段／後段／併用／正本が別）
3. **既存スキルの `## 接続` に張り返す** — 少なくとも「前段になるスキルの後段」に自分を足す
4. このファイルの層の表に追加する
5. `docs/command-registry.md` のスキル台帳に追加する
6. 手順書（`procedures/`）か部品（`docs/parts/`）から到達できるようにする
7. golden（`docs/evals.md`）と Tier 2（`procedures/takumi-verify.md` — **V番号の正本はここ1つだけ**）を足す
8. `python3 scripts/lint.py` が緑になるまで直す

## 注意

- **接続は「必ずこの順に読め」という意味ではない。** 実務は途中から始まるほうが多く、
  その場合は**前段が埋まっているかを確かめて、埋まっていなければそこへ戻る**ために使う
- **相互リンクは強制しない。** A→B が正しくても B→A が不要な組み合わせはある
  （例: 全生成スキル → `ad-compliance-jp` は片方向でよい）
- **手順書（`procedures/`）と部品（`docs/parts/`）はこの地図の外側**にある。
  業務の入口は常にコマンド／手順書で、スキルはその中から開かれる（session-rules (3)）
