## 設計上の帰結（v2.0.0）

E4・E5 から、TAKUMI-CMO は **「hook が効かなくても壊れない」設計**を前提にする:

- ゼロ広告費は hook（url-guard）だけでなく **ドメイン層でも強制**する — `takumi/domain/kpi_tree.py` の `KpiNode` が
  CAC/LTV/ROAS/CPA/広告費 等の有料指標を ValueError で拒否するため、KPIツリーに有料前提が入り込めない
- ブランド区画の分離は hook（brand-isolation-guard）だけでなく **`BrandPartition.contains()` の境界判定**で担保する
- 実機で hook が沈黙していることを検知したら、一括送出・金銭近傍・無人運用は行わず cloud セッションに移る（TESTING.md 二層構造の Tier 2 参照）
