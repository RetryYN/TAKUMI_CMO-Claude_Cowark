# 部品: 規模に合わせた戦略（scale-strategy）

**タスク型: 分析／計画。** 自社の規模と立場を確定し、**1位を取れる範囲**まで市場を細分化して、
そこに時間を集中するまでを1本で回す。

> **作法の正本は `skills/scale-strategy-jp`。着手前に必ず Read する**（相対不達なら Glob）。
> 判断基準・出典の限界（**数値は原典未取得**）はそちらに書いてある。
>
> **前段**: アクティブブランドを確定する（未確定なら /ブランド）。
> 記録は `knowledge/brands/<slug>/strategy/` にスコープされる（Brand Isolation Guard 対象）。

## この部品の位置

`docs/parts/foundation-analysis.md` の **②STP の直後、③ビジネスモデルの手前**。

```
① 環境 → ①b 人物像 → ② STP（誰に売るか）
                              ↓  誰に売るかは決まった。では**どの範囲で1位を取るのか**
                        ★ この部品（規模の確定 → 細分化 → 一点集中）
                              ↓  範囲が決まった。ではその範囲で儲かるのか
                        ③ ビジネスモデル／キャッシュフロー
```

**STP が「誰に」を決め、この部品が「どこまで狭めるか」を決める。**
`skills/winning-position-jp`（どんな土俵か）とは補完関係にある —
勝ち筋が**土俵の性質**を選ぶのに対し、ここは**範囲の広さ**を決める。

## 使う場面

- 「大手に勝てない」「競合が強すぎる」
- 「どこで1位を取ればいいか」「どこまで絞ればいいか」
- 一人・少人数での事業戦略
- 「No.1と名乗ってよいか」の判断

## 段取り

### 1. 規模と立場を確定する

| 確認 | 記録 |
|---|---|
| **投下できる時間**（週あたり実働） | ここが**兵力**（金では増やせない）。→ `docs/parts/capacity-plan.md` |
| 人数 | 個人／少人数（2〜10）／中小（10〜） |
| **立場** | **弱者か強者か**（ほぼ常に弱者。日本の事業者の84.5%は小規模事業者） |
| 主な競合の規模 | 相手が大手なら**ミート戦略（同質化）を前提に置く** |

**「兵力＝時間」を明示的に書く。** ゼロ広告費では金で兵力を増やせないので、
**集中する以外に手が無い**という前提をここで固定する。

### 2. 市場の定義（分母）を書く

**地域 × 客層 × 用途 × 期間**まで書く。

```python
from takumi.domain.market_share import MarketShare
ms = MarketShare("名古屋市の個人向けピアノ教室（月謝制・2026年）", 0.30)
```

**分母が空だと `ValueError`。** 範囲を狭めればいくらでも「1位」を作れてしまい、
**対外的に主張すれば No.1 表示の根拠を問われる**（→ `skills/ad-compliance-jp`）。

**シェアが推定できないことは多い。** そのときは**「推定不能」と書く**。
代わりに観測できるもの（特定クエリでの露出・コミュニティでの言及・紹介の発生数）で見る。
**推測の数字を書かない。**

### 3. 1位との差を測り、射程距離を判定する

```python
from takumi.domain.market_share import LanchesterMode
ms.verdict(leader_share=0.45, mode=LanchesterMode.FIRST_LAW)
ms.is_within_striking_distance(0.45, LanchesterMode.FIRST_LAW)
```

| 場 | 逆転困難になる差 |
|---|---|
| 第一法則（局地戦・一騎討ち・2社競合） | **3倍** |
| 第二法則（広域戦・多数競合） | **√3倍（約1.7倍）** |

- **射程内** → 4へ（足下の敵から取る）
- **射程外** → 5へ（**細分化して範囲を作り直す**。「もっと頑張る」で解決しない）
- **自社シェア0** → 倍率は**判定不能**（無限大ではない）。5へ

### 4. 射程内なら — 足下の敵から取る

**いきなり首位に挑まない。** 1ランク下を狙う（3位なら4位を）。

**同時に、下限目標値（26.1%）を確認する。**
1位を名乗っていても、ここを下回っていれば**安定していない**。

### 5. 射程外なら — 1位を取れるまで細分化する

細分化の軸: **地域 / 客層 / 用途 / 商品 / 販売経路 / 時期**。

**止める条件**（どちらかを満たしたら、それ以上狭めない）:

- **その範囲の需要が事業として成立しない**（→ `skills/business-model-jp` の損益分岐点）
- **顧客がその括りを理解できない**（説明に3段落要る括りは成立しない）

**狭めた範囲を1文で言えること。** 言えないなら細分化ではなく言い訳。

### 6. 弱者の戦法に落とす

| 戦法 | 実装先 |
|---|---|
| **局地戦** | テーマ・検索意図を絞る（→ `skills/seo-jp`） |
| **一騎討ち戦** | 誰も答えていない問い（→ `skills/seo-jp`「向かれていない読み手」） |
| **接近戦** | メール・紹介・応対（→ `/メール`・`/エンゲージメント`・`skills/referral-advocacy-jp`） |
| **一点集中** | 媒体もテーマも絞る（→ `docs/parts/capacity-plan.md`） |
| **陽動戦** | 大手が扱えない話題・言えない立場（→ `skills/winning-position-jp` §2） |

**模倣されたら終わる差別化を選ばない。** 強者はミート戦略（同質化）で潰しにくる。
**「真似するには相手が何かを失う」ものを選ぶ。**

### 7. 一点集中を実行に落とす（**他を落とすまでが仕事**）

1. 決めた1点に時間を寄せる
2. **落とすものを明示する**（→ `docs/parts/capacity-plan.md` で埋まり具合を出し、100%超なら落とす）
3. **落とした理由を記録する**（毎回同じ議論をやり直さないため）

**集中を決めたのに他を落とさないのは、集中していない。**

### 8. 記録して接続する

1. `knowledge/brands/<slug>/strategy/scale-position.md` に:
   - 規模と立場（兵力＝週あたり実働時間）
   - **市場の定義（分母）**／シェア（推定不能なら「不能」）
   - 1位との差と射程判定
   - **1位を取りにいく範囲（1文）**
   - 採る弱者戦法／**落とすもの**
   - **外れたと分かる条件**（→ `skills/hypothesis-design-jp`）
2. `skills/winning-position-jp` の `winning-position.md` と突き合わせる（**土俵の性質 × 範囲の広さ**）
3. `/戦略` のロードマップへ渡す
4. 主張の言語化は `skills/messaging-design-jp`

## 禁止・注意

- **分母を書かずに「1位」「No.1」を扱う**（対外表示なら根拠を問われる → `skills/ad-compliance-jp`）
- **推定の数字をシェアとして記録する**（推定不能なら「不能」と書く）
- **射程外の相手を正面から追う計画を作る**（場所を変えるのが正解）
- **細分化しすぎて事業が成立しない範囲を選ぶ**（→ 損益分岐点で確かめる）
- **一点集中を決めて、落とすものを決めない**
- **シェア目標値・射程距離を「科学的根拠」として対外資料に引用する**
  （**原典未取得・学術的検証も未確認**。判断の目安として内部で使う → 正本 §0）
- **競合を名指しで貶める比較**（景表法の対象）
