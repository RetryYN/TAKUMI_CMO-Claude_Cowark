# /匠発信 ▸ 自社ブログの運営（takumi-ownedmedia）

TAKUMI-CMO の集客・ブランディングの中核＝**オウンドメディア（自社ブログ）**。**WordPress を既定**とし（brand.yaml / setup で別プラットフォーム＝note/Ghost 等が指定されていればそれに従う）、記事の公開・更新・構造設計・SEO・更新巡回を担う。ゼロ広告費。

> **企画の前に `skills/breakout-content-jp` を読む。** 「伸びなかった」で終わらせず、**①配信 ②選択 ③完走 ④行動**のどこで落ちるかを設計段階で分けて考える。**当たった1本は分析して型にし、モダリティ違いで横展開する**（新テーマを1本足すより濃い）。
> **公開の時期は `skills/demand-timing-jp` で決める。** 検索は**評価が乗るまでに時間がかかる**ため、需要の山の**3〜6か月前**に公開する（山の当日に出しても間に合わない）。**新規記事を書く前に、既存記事の更新で同じ山を取れないかを先に見る** — 既に評価が乗っている記事を直すほうが速く、安い。**閑散期に更新を止めない**（山のときに配信面での評価が落ちている）。
> **前段**: アクティブブランドを確定する（未確定なら /匠設定）。記憶は `knowledge/brands/<slug>/channels/ownedmedia/` にスコープ（原則4）。
> **役割分担**: 記事の中身（本文・アイキャッチ・図解）は **/匠発信** が作る。このパックは**媒体としてのブログ運営**（公開・構造・SEO・巡回）を担う。

## WordPress の前提（既定）

- ログインは人間が行う（Credential Guard）。管理画面 URL は brand.yaml / `knowledge/config` に記録。
- 投稿・更新・公開は**変更操作** → takumi-start のゲート下。**公開（publish）は不可逆送出** → pre-send-verifier 監査 + ユーザー承認。まずは**下書き保存を既定**にし、公開はユーザー承認後。
- 通常のエディタ操作（ブロック/クラシック）。SEOプラグイン（Yoast / RankMath 等）があればメタ・スラッグ・OGPを設定。**有料プラン・課金・広告は触らない**（ゼロ課金ゲート）。

## 定常運用

- **コンテンツ監査**（半年〜年1回、および「記事は増えたのに成果が伸びない」と言われたとき）: **`docs/parts/content-audit.md`** で全体を棚卸しし **伸ばす／直す／統合する／落とす** の4分類にする（作法の正本は `skills/content-ops-jp`）。**新規制作の前に、既存の確認を飛ばさない** — 既に評価が乗っている記事を直すほうが速く安い。**削除・統合は不可逆**なので人間の承認を経る。
- **更新巡回**（週次等）: 公開済み記事の順位・流入の変化、リライト候補、内部リンクの穴を点検（seo-jp / cro-jp / content-ops-jp）。締めに /匠計測 のダッシュボード更新。
- **記事カレンダー**: KPIツリーのドライバー（オーガニック流入・指名検索）に効くテーマを /匠戦略 のロードマップから落として計画化。
